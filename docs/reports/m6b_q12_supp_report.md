## 一、实验写法（裁决未写死、由我选定的部分，请设计会话确认）

1. **两档的标准化。** 档乙与档丙都把湿度与气压两个通道的中位数与分母一并换成冻结参数（版本一：气压中位数 101,798 帕、尺度 900 帕），温度、气体、光照仍用版本三（温度尺度 2.61，版本一为 1.60）。训练、早停、标定与评分四处用同一组混合参数。初始模型仍按版本一评分，与第一轮相同。
2. **档丙的训练集。** 取 2022-03-28 当地零点（03-27 23:00 UTC）起的 N 个当地日：N 取三时为 03-28 至 03-30，N 取七时为 03-28 至 04-03。三段划分、净化与超参数与第一轮相同。
3. **平稳段三个口径。**
   - 口径一：训练集之后的七个当地日，不含注入日 04-05。档乙为 03-28 至 04-03，共七天；档丙 N 取三时为 03-31 至 04-06 去掉 04-05，N 取七时为 04-04 至 04-10 去掉 04-05，各六天。
   - 口径二：v34 日表中 E 的平稳日 03-29、03-30、04-17、04-23、04-24，去掉落在训练集内的日子。档乙五天都在；档丙的 03-29、03-30 落在训练集内，所以**档丙的口径二与口径三是同一组日子**，两列数值相同。
   - 口径三：04-17、04-23、04-24，两档共同，且都在两档训练集之后。
4. **初始模型在档丙口径上的评价。** 档丙的口径一随 N 变化，所以初始模型按 N 取三、取七各评价一次（只评价、不训练，模型文件不改写）。档乙的初始模型行用 N 取七的口径评价，其口径一、口径二与第一轮的初始模型行逐字段相同。
5. **规模。** 两档共六十五次运行：档乙五次初始模型评估、三十次重训；档丙十次初始模型评估、二十次重训。全部完成，无失败。开发机在 03:40 UTC 前后重启过一次，中断的两次重训从头重跑，已完成的结果行不受影响。

四格（N 取三、七，热、冷启动）全部记为**「档丙更低」**，五个种子的差值全部为负，幅度为负零点一五至负零点七九。档丙口径三的中位数为 0.072 至 0.086，档乙同格为 0.556 至 0.825。口径一两档的日子不同，只作描述：档丙也全部更低。

### 判定五：N 是否仍在改善

- **档乙：**两种启动方式下，十四对七在口径一、口径二上都有系统改善（五个种子全部）；七对三在平稳段上没有改善，冷启动在口径一、口径二上系统变差，热启动在口径二上系统变差；热启动七对三的检出段数系统地更多，但这两档召回饱和（判定三），检出段数多是误报多的结果。按写定规则，三与七都不满足「更大的 N 不再改善」，十四是网格上限，**判定五在档乙内选不出 N**，与第一轮相同。超阈率随 N 不单调：七最差，十四最好。
- **档丙：**七对三在四个度量上都没有系统改善；冷启动七对三在口径一、口径二上系统变差。按写定规则，**档丙两种启动方式都取 N 等于三**。
  - **写定规则的一处疏漏（如实登记）：**档丙的口径一随 N 变化（N 取三为 03-31 至 04-06，N 取七为 04-04 至 04-10，都去掉 04-05），所以七对三的口径一比较的是不同的日子；初始模型在这两组日子上也从 0.160 升到 0.236。写定规则时我没有把这一点排除。只看口径二（档丙两档的口径二是同一组日子），冷启动七对三仍系统变差（五对中四对，幅度 0.007 至 0.014），热启动仍无系统差别，所以结论「取三」不变。

### 耗时与轮数

- 档丙的热启动十次中有九次在第二十一至二十四轮早停，最佳轮为第一至第四轮（耐心二十），耗时四十至一百一十秒，即模型几乎停在初始模型的权重上，只是在新数据上重新标定。另一次（种子 2、N 取七）跑到第一百一十轮。档丙冷启动为三十三至一百三十二轮。
- 档乙热、冷启动的轮数相近：N 取三时中位数为一百四十八轮对一百五十二轮，N 取七为一百三十九对八十四，N 取十四为一百零九对一百。
- 耗时是开发机上两个进程并行的墙钟时间，只宜作相对比较。

4. **注入幅度在两种温度尺度下的大小。**04-05 的六段注入都在温度通道上，按注入真值表 `docs/m3_a4/full_fix/inject-truth.csv`，三段尖峰与三段阶跃的幅度都是 4.56、9.12、18.24（原始单位）。按版本一的温度尺度 1.60 计为 2.85、5.70、11.4 个尺度；按版本三的 2.61 计为 1.75、3.49、6.99 个尺度。初始模型按版本一评分，两档的重训模型按版本三评分。结果行没有逐段记录哪一段被检出，所以档丙漏检的是哪几段，本报告无法给出。

## 四、需要设计会话判断的事项

1. **第一节的写法。**特别是第 3 条：档丙口径二与口径三相同；第 4 条：初始模型在档丙口径上单独评价。
2. **热冷启动条款的读法。**1.39 版裁决第三项写的是「若档乙或档丙上热启动在平稳段与召回上都不系统地优于冷启动，一级取冷启动」。本次结果是：召回上热启动五格都不系统地更好；平稳段上档乙 N 取三、取七与档丙 N 取七三格系统地更好，档乙 N 取十四与档丙 N 取三两格没有差别。
   - 读作「两者之一都不优于」，即平稳段与召回都没有优势时才取冷启动：五格中三格热启动在平稳段上有优势，条件不成立。
   - 读作「必须两者都优于才取热启动」：召回上没有一格成立，条件成立，取冷启动。
   - 只看判定五在档丙选出的 N 取三：两种读法都给出冷启动（平稳段与召回都无系统差别）。
   另需注意，档丙 N 取七的平稳段优势只有四百一十七窗中一至八窗，而档丙热启动几乎停在初始权重上（第二节「耗时与轮数」）。
3. **训练窗口的起点与 N。**判定二支持生效之后（档丙）；判定五在档丙取 N 等于三，在档乙选不出 N。档丙生效后侧意味着一级在线时旧模型要继续服务 N 天（在线实现已支持，见 `docs/reports/m6b_l12_impl_notes.md` 第二节第 2 条）。
4. **档丙召回低于初始模型基线。**检出两至三段，基线为四段（第二节判定三、第三节第 4 条）。这是否影响一级的采用，或者是否需要另行核查逐段检出，由设计会话决定。我没有改动阈值或任何口径。
5. **档乙的结果。**湿度与气压用冻结参数之后，档乙仍「明显高于初始模型」，超阈率随 N 不单调。第三节第 1 条列出了训练集覆盖范围与评分日气压的对照，供设计会话判断这是否属于理论回传第二十九条（训练窗口锚定在变化点之后）所描述的现象。
6. **判定五的疏漏。**口径一在档丙两档 N 之间不可比（第二节判定五）。结论不受影响，但今后若沿用这一判据，需要改为只用跨 N 相同的日子。
