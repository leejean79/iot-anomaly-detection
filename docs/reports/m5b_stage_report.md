## 二、V-M5b-1（单元测试与常量表核对）：通过

1. **常量表与 scipy 一致**：六种（置信度，鲁棒度）组合、窗上限 2,016，`m5b/check_tables.py` 用 scipy 逐个窗长穷举，切点不同的窗长数
   全部为 0；F 临界值最大相对误差 2.8e−13 至 4.2e−13，t 临界值 1.6e−13 至 1.8e−13，远小于交接文档要求的一百万分之一（2026-10-21 重新
   运行确认）。首个有根窗长：置信度 0.99 时鲁棒度 0.3 为 433、0.5 为 179；置信度 0.999 时分别为 665 与 274；鲁棒度 0.1 在 2,016 以内
   无根（对半切分）。小时粒度用的六张窗上限 336 的表，与对应 2,016 表的前 307 行逐行相同。
2. **数值方法与作者一致**：按作者代码的自由度口径生成的 Java 表，与作者预先算好的四个切点文件（置信度 0.99 与 0.999、鲁棒度 0.1 与
   0.5，窗长 30 至 2,016）逐窗长相同。作者仓库无许可证，文件未放入本仓库（核对方法见实现说明第二节）。
3. **单元测试**：`OptWinTest` 五个（常量表与 scipy、合成流事件与 Python 逐位相同、独立同分布平稳流候选率 0.035% 低于论文上界 1%、
   持续性核对的状态转移、序列化恢复）与 `M5bFunctionTest` 三个（十分钟与小时粒度下在线事件与离线逻辑逐条相同、检查点恢复后不变、
   快照每 60 秒一条），全量 134 个测试全部通过（沙箱 JDK 21；JDK 11 以用户构建为准）。
4. **Java 与 Python 逐位相同**：36 种组合、两种元素流（剔除与不剔除注入），事件清单全部逐条相同。

## 三、V-M5b-2（离线网格）：通过（0.98 版裁决第一节）

按运行前写定、2026-10-21 确认的口径运行。默认组合（置信度 0.99、鲁棒度 0.5、十分钟粒度、K = 36）：50 个平稳设备日上确认 1 条，
11 条候选中 10 条被持续性核对撤销；三月事件尾段八台中七台确认，其中六台的第一次确认由方差检验触发；17 个尺度漂移设备日中 7 个有确认，
全部由方差检验触发；C 的日照直射五段四段有候选、零确认；04-17 傍晚气体上升八台七台有候选、零确认；十四段注入七段有候选、零确认；
盲区内错过 2 段（D 的 03-27 与 04-10）。第四节规则的结论为保持默认组合，0.98 版确认。详见 `docs/reports/m5b_offline_grid.md`。

0.98 版的处置：不允许方差检验独立报警，纯离散变化归告警率流（关闭理论线回传第十八条的开放问题）；不给持续性核对加最小绝对幅度，
登记开放问题第十三条（零级响应的触发是否设以主分为单位的最小幅度，依据为 `docs/m5b/grid/confirms.csv` 的确认幅度分布）。
