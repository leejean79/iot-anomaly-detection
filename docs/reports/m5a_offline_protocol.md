## 二、参照直方图与两种统计量

1. **箱**：对参照样本排序，取第 ⌊j(m − 1)/400⌋ 个顺序统计量（j = 0 … 400），去重得到边界 e₀ < … < e_K（K ≤ 400）。箱为下溢 (−∞, e₀)、
   [e₀, e₁]、(e₁, e₂] … (e_{K−1}, e_K]、上溢 (e_K, +∞)，共 K + 2 个。
2. **分布检验统计量 D**：在每个箱的右端比较当日与参照的累积频率，取绝对差的最大值。渐近显著性 p = Q_KS(√(nm/(n + m)) · D)，
   Q_KS(λ) = 2 Σ_{k≥1} (−1)^{k−1} e^{−2k²λ²}，n、m 为当日与参照的读数数。另给出精确经验累积分布的 D 作为对照（分箱误差）。
3. **似然比（G）检验**：参照在每个箱（含两个溢出箱）上的频数各加 0.5 再归一化，作为期望比例 p_b；G = 2 Σ O_b ln(O_b / (n p_b))（O_b = 0 的
   项为 0），自由度 K + 1，按卡方分布取显著性。效应量 = G ÷ 2n（KL 散度的估计，正偏差约为（非空箱数 − 1）÷ 2n，不做校正，报告中注明）。
4. **冻结的门槛**（1.05 版）：

| 通道 | D 零 | D 的最大值（来源） | G 零（G ÷ 2n） | G ÷ 2n 的最大值（来源） | 推导的设备日 |
| --- | --- | --- | --- | --- | --- |
| 温度 | 0.38 | 0.3765（G 03-07） | 0.75 | 0.74194（F 03-07） | 56 |
| 湿度 | 0.73 | 0.7268（F 03-07） | 1.57 | 1.56056（H 03-07） | 56 |
| 气压 | 0.84 | 0.8364（B 03-06） | 1.84 | 1.83934（B 03-06） | 56 |
| 气体 | 0.43 | 0.4252（B 03-03） | 0.77 | 0.76315（B 03-03） | 56 |
| 光照 | 0.51 | 0.5046（E 03-04） | 1.24 | 1.23128（A 03-07） | 49（剔除 G） |

   推导：每个通道在八台设备与七个完整标定日（03-01 至 03-07）上取最大值，向上取整到两位小数；光照剔除设备 G（1.04 版）。G 零按 1.05 版的
   平滑规则与顺序统计量边界重算（`docs/reports/m5a_reference_check.md`，2026-10-25），与平滑之前的值在两位小数上相同。

   显著性水平 0.01，五个通道邦费罗尼校正为 0.002。

## 三、三族信号的事件定义

1. **长记忆事件**（主方案）：某台某日某通道，p < 0.002 且 D > D 零（该通道）。一台一日可有多个通道的事件。
2. **逐日统计量**：偏移 =（当日中位数 − 参照中位数）÷ 参照的 P10–P90 宽度；宽度倍数 = 当日 P10–P90 宽度 ÷ 参照的 P10–P90 宽度（百分位数
   按线性插值）。「越位置门槛」= |偏移| ≥ 0.5；「越尺度门槛」= 宽度倍数 > 3.0。逐日统计量只产生日记录，不产生漂移事件；判读中「逐日统计量
   超门槛」指任一通道越位置或尺度门槛。
3. **离群率事件**：十分钟元素送入性能层同一份最优窗口检测器与持续性核对，参数为性能层收口时的默认组合（置信度 0.99、鲁棒度 0.5、窗上限
   2,016、K = 36）；候选、确认、撤销的定义与性能层完全相同。
4. **质量门控**（1.03 版）：一个设备日若「缺轮比例 = 1 − 实到轮数 ÷ 应有轮数」超过 20%，或「守卫打标轮数 ÷ 应有轮数」超过 20%，记为不可判，
   不做第一、二族的统计，只给出带原因的记录。应有轮数 = 当地日秒数 ÷ 10（一般 8,640，03-27 为 8,280）。守卫打标轮 = 数据接入模块
   `RepeatRunGuard` 写了 `stuckMask` 的轮，即任一通道连续完全相同的原始读数（以轮计；该通道缺失时不延长也不打断；相邻读数相隔超过 60 秒、
   设备冷启动时断开）达到 `docs/stuck_guard/thresholds.env` 中该台该通道的阈值之后的轮；底值集合内的值形成的底值游程只写 `floorMask`，不计。
   离线按 `RepeatRunGuard` 的规则移植计算。第三族不受质量门控（性能层同样没有）。

## 四、片段与归属

- **日期**：第一、二族按当地日；第三族与性能层一样按世界协调时的日期归属平稳日、尺度漂移日（这两份清单都是按世界协调时的日子登记的），
  当地日与世界协调时日在 03-27 之后相差一小时，报告中注明。
- **离群率事件的归属**：与性能层相同，候选时刻落在 [段开始, 段结束 + 6 小时] 之内算该段的候选；确认与撤销按它所核对的候选归属。
- **长记忆与逐日统计量的归属**：落在与该段有交集的当地日上的事件与越门槛，算该段的。
- **平稳日**：`docs/m3_inject/v34/v34_daily.csv` 中各台 `stable_<设备>` 为真的日子（判读清单不变，1.03 版）。
- **尺度漂移日**：与性能层口径第三条相同（`docs/m3_marapr/daily_channel_profile_ref0308.csv`，任一检测通道宽度倍数超过 3.0）。
- **四月五个共模气体时段**：`docs/fleet_episodes/episodes.csv` 的五个时段；段 = [第一个候选 − 12 小时, 最后一次确认]（世界协调时），与时段
  剖面报告的峰值搜索区间相同。

## 五、九条判读口径的操作定义

1. **平稳日上的事件数**：逐台、逐族给出：长记忆事件数、逐日统计量超门槛的天数（位置、尺度分列）、离群率的确认数与候选数（按确认或候选
   时刻所在的日子）。另给出逐台平稳日天数与其中不可判的天数。**长记忆事件与逐日统计量按通道分列**（2026-10-25 设计会话补充），并分为下列
   几类分别说明，分类在运行前写定、不看结果调整：
   - **G 的光照单独列出，不计入「未预期的平稳日事件」**：成因是已登记的参照污染——标定窗口的前六天落在连续人工照明之中（数据事实第三十四条），
     03-06 之后正常的昼夜形态相对这份参照就是「分布变了」；它恰好是零级响应要消解的情形。
   - **其余设备的光照**：随三月到四月日照延长，长记忆事件可能逐日增多，按理论回传第十五条是长记忆看季节趋势的预期行为，报告中逐日给出各台光照
     的事件数与 D，单独说明，不计入「未预期的平稳日事件」。
   - **气压与湿度**：按理论回传第二十一条解读——日间变化是天气驱动、全机队同步的；报告中给出这两个通道在每个平稳日上报警的设备数（同步程度），
     单独说明，不计入「未预期的平稳日事件」。
   - **温度与气体**：上述三类之外的平稳日事件，计为「未预期的平稳日事件」，逐条列出。
2. **三月事件（03-22 至 03-27）**：逐台逐通道给出第一次长记忆事件的日期、第一次越位置门槛与越尺度门槛的日期；逐台给出归属于该段
   （[03-22 00:00, 03-28 00:00) UTC）的第一个离群率候选与第一次确认的时刻与检验。
3. **尺度漂移日**：逐个设备日给出各通道的宽度倍数（本阶段参照）、是否越尺度门槛、是否有长记忆事件及其通道；汇总「越尺度门槛且有长记忆」
   「只越尺度门槛」「只有长记忆」「两者都没有」四类的设备日数。
4. **五个共模气体时段**：逐时段逐台给出气体通道在相关当地日上是否有长记忆事件、是否越位置或尺度门槛，以及归属于该段的离群率候选与确认；
   逐时段给出同一当地日气体长记忆报警的设备数（交接文档预期至少七台，只记录不作判据）。
5. **C 的日照直射与傍晚气体上升**（与性能层口径第四条相同的段）：C 在五个日照日的光照与温度通道是否有长记忆事件、是否越门槛；归属于各段的
   离群率候选与确认；04-17 傍晚八台同样。
6. **注入（不剔除的一遍）**：十四段逐段给出归属于它的离群率候选与确认；注入当日 E 被注入通道的长记忆事件与越门槛情况，并与剔除的一遍并排。
7. **夏令时切换日**：03-25 至 03-29 五天，逐台逐通道按当地日与按世界协调时日各算一次长记忆的 D 与事件，给出两者的差；另给出两种日界下
   逐小时读数数的分布，说明 03-27 当地日只有 23 小时。
8. **两层同报表**：对第 2、4、5、6 条的每一段与每个尺度漂移日，逐台列出性能层默认组合的候选与确认时刻（`docs/m5b/grid/events/` 的默认组合
   事件清单）、数据层的长记忆事件（日期与通道）、逐日统计量越门槛（日期与类型）、离群率候选与确认时刻，并按时刻排出先后。
9. **理论第五项验证**：三种方案在第 1、2、4 条上的结果并排（第六节）。

另给出验收项四所需的时延表：三月事件起点（03-22 00:00 UTC）到第一次长记忆事件（以日计）、第一次越门槛（以日计）、第一个离群率候选与确认
（以分钟和元素数计），逐台。

## 六、三种统计方案（理论第五项验证，1.03 版采纳）

均以设备日为单位，一个设备日只要有一个通道报警即记为该方案报警。

| 方案 | 每个通道的报警条件 | 校正 | 效应量门槛 |
| --- | --- | --- | --- |
| 甲，原文方案 | p < 0.01（等价于把各通道统计量的最大值与未校正的临界值比较） | 无 | 无 |
| 乙，分布检验加邦费罗尼（主方案） | p < 0.002 且 D > D 零 | 0.01 ÷ 5 | D 零（逐通道） |
| 乙′，乙只保留显著性 | p < 0.002 | 0.01 ÷ 5 | 无 |
| 丙，卡方校准似然比 | G 的卡方显著性 < 0.002 且 G ÷ 2n > G 零 | 0.01 ÷ 5 | G 零（逐通道） |
| 丙′，丙只保留显著性 | G 的卡方显著性 < 0.002 | 0.01 ÷ 5 | 无 |

报告每种方案在平稳日上的报警设备日数、三月事件各台的第一次报警日期，以及五个共模时段同日报警的设备数。乙′、丙′用来记录「一天八千多个
样本下显著性一道门几乎总是通过」这一事实（1.04 版第二节）。

## 七、移植与等值

- `Injector` 的四种注入移植到 Python，用 `inject-truth.csv` 的参数施加；单元测试与 Java 的 `Injector` 在同一段合成序列上逐值对照。
- `RepeatRunGuard` 的游程规则移植到 Python，用于质量门控；与 Java 在合成序列上逐轮对照。
- 分布检验的 D、渐近显著性与 G 检验与 scipy 对照：D 与 `ks_2samp` 的统计量对照；显著性按第二节的极限分布公式，与
  `kstwobign.sf(√(nm/(n+m))·D)` 对照（注意 `ks_2samp(method="asymp")` 用的是样本量取整后的有限样本分布 `kstwo`，在本数据的样本量下
  显著性相差约百分之五至七，本口径采用极限分布，Java 与 Python 同用）；G 检验与 `power_divergence(lambda_="log-likelihood")`、卡方上尾与
  `chi2.sf` 对照。
- 第三族用性能层的 Python 参考实现（`m5b/optwin_offline.py`），与性能层已证明的 Java 等值一致。

## 八、两种参照的并列（1.03 版）
