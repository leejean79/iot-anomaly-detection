## 二、核对结果

1. **数值方法与作者一致**：按作者代码的自由度公式生成的 Java 常量表，与作者预先算好的切点文件逐窗长相同。比对了四个文件：
   置信度 0.99 与 0.999、鲁棒度 0.1 与 0.5，窗长 30 至 2,016，切点不同的窗长数都是 0。作者仓库没有许可证，所以作者文件不放进本仓库；
   核对时用 `git clone https://github.com/maurodlt/OPTWIN`（提交 f43731b），再运行 `python3 m5b/check_tables.py --table <表> --authors-dir <仓库>/pre_computed_cuts`。
2. **论文口径的常量表与 scipy 一致**：六种（置信度，鲁棒度）组合、窗上限 2,016，切点与 scipy 逐个穷举的结果完全相同；F 与 t 临界值的
   最大相对误差约为 4e−13，远小于交接文档要求的一百万分之一。各组合的首个有根窗长：置信度 0.99 时，鲁棒度 0.3 为 433、0.5 为 179；
   置信度 0.999 时，分别为 665 与 274；鲁棒度 0.1 在 2,016 以内无解。
3. **Java 与 Python 逐位相同**：在真实元素流（`docs/m5b/streams_10min.csv`，默认组合：置信度 0.99、鲁棒度 0.5、十分钟粒度、
   K = 36）上，两边都给出 295 条事件，逐条逐列相同。这只是等值核对，不是离线实验的判读。
4. **单元测试**：五个新测试全部通过，全量 131 个测试全部通过（JDK 21 下运行，JDK 11 下请以用户构建为准）。具体覆盖：
   - 常量表与 scipy 一致；
   - 合成流上的事件与 Python 逐位相同：均值漂移在第 600 个元素开始，第 616 个元素由 t 检验报警；方差漂移第 611 个元素由 F 检验报警；
   - 独立同分布的平稳合成流有 20,000 个元素、7 个候选，候选率 0.035%，低于论文上界 1%。这个断言只用在满足论文前提（独立同分布）的
     合成流上；真实主分流不满足前提，按裁决补充第一节，只报告实测值、不设门槛；
   - 持续性核对的确认、撤销，以及核对中出现新候选的情形；
   - 序列化之后恢复继续运行，结果与不中断的一次相同。

## 四、文献勘误（报告中单列一节）

1. 算法 2 第 5 行写 |W| ≥ max_length 时移除最旧元素，与第 47 页正文「W 超过 w_max 时移除」不一致；按正文实现（0.94 版第二条）。
2. 式 4.7 的正文说 F 检验分子的自由度为 |W新|−1，公式写作 f_ppf(δ′, ν|W|−1, (1−ν)|W|−1)，即分子为 |W历|−1；按公式实现
   （0.93 版裁决补充第一节）。
3. 式 4.11 分母第一项的分子写作 σ²新/|W历|，按韦尔奇自由度的标准形式应为 σ²历/|W历|；式 4.12 的推导没有受影响。
4. 作者公开代码与论文的两处差异：t 统计量分母用标准差，自由度的方差比项用 1/f_ppf²；我们按论文实现（0.93 版裁决补充第一节）。
