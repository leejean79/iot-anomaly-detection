# M5b 离线实验的操作口径（实验运行之前写定，2026-10-20）

依据：交接文档 `docs/handover/handover_m5b_stage_zh.md` 第零节决定六与第四节（判读口径一至七条）；10 月 19 日裁决书第五、六点；
0.93、0.94 版裁决。交接文档要求判读口径在实验运行之前写定、不以结果反推参数。本文把七条口径落成可执行的定义，在提交本文之前
**没有运行网格**。此前为了核对 Java 与 Python 的等值，默认组合在剔除注入后的数据上跑过一次，只看到事件总数（候选 154 条、确认 51 条），
没有按任何口径判读。

## 一、数据与网格

- 元素流：`docs/m5b/streams_10min.csv`（每个评分窗一个元素，主分）与 `streams_hourly.csv`（按世界协调时整点小时取主分中位数），由
  `m5b/prepare_streams.py` 从 `docs/m3_a4/full_fix/m3_scores.jsonl` 生成，设备 E 剔除注入区间及其后一个窗长。判读口径第七条另用
  不剔除的元素流（`--no-exclude` 生成，文件名后缀 `_with_injection`）。
- 网格：置信度 {0.99, 0.999} × 鲁棒度 {0.1, 0.3, 0.5} × 粒度 {十分钟, 小时} × K {18, 36, 72}，共 36 种组合。窗上限为十四天的
  元素数：十分钟粒度 2,016，小时粒度 336。K 按交接文档写成元素数，所以小时粒度下 K = 18、36、72 分别是 18、36、72 小时，而十分钟
  粒度下是 3、6、12 小时；报告中两种单位并列。鲁棒度 0.1 一档在报告中标注为「对半切分」（0.92 版第三点）。
- 检测器与持续性核对按 `com.leejean.m5` 的实现，Python 参考实现读 Java 生成的同一张常量表；每种组合都核对 Java 与 Python 的事件
  清单逐条相同。
- 基线：加权霍夫丁漂移检测器，river 0.26 的 `river.drift.binary.HDDMW`，文献默认参数（漂移置信度 0.001、预警置信度 0.005、
  λ = 0.05、单侧检验），输入每个评分窗的超阈标记（0 或 1），逐台独立运行，只在十分钟粒度上运行。它的「报警」记为基线候选。
  基线看的是超阈标记序列，主检测器看的是主分，两者输入不同，比较的是「对同一段时间的判断」。

## 二、日期与归属

- **日期**：判读用世界协调时的日期，与平稳日、通道剖面的口径一致（这些都是按世界协调时的日子算的）。事件清单同时给出世界协调时与
  布里斯托当地时间（CLAUDE.md 第 8 节）。
- **事件归属到某一段**：候选的时刻落在 [该段开始, 该段结束 + 6 小时] 之内，就算该段的候选。确认与撤销按它所核对的那个候选的时刻
  （`candidate_ts`）归属。6 小时取的是默认 K 在十分钟粒度下的时长，各组合统一使用，不随 K 变。

## 三、七条口径的定义

1. **平稳日上的确认漂移数**：逐台统计确认事件的时刻落在该台平稳日上的条数，平稳日取 `docs/m3_inject/v34/v34_daily.csv` 中该台的
   `stable_<设备>` 为真的日子（位置加尺度判据，尺度门槛 3.0）；另给出每台的平稳日天数，以及每个平稳日的确认数。
2. **三月事件尾段**（03-24 至 03-27，世界协调时 03-24 00:00 至 03-28 00:00）：逐台给出是否有确认、第一次确认的时刻与它的检验
   （F 或 T），以及这四天内的候选数。B、H 的评分分别从 03-26 15:12 与 03-26 00:03（当地时间）才开始，表中注明。
3. **尺度漂移日**：逐台取 03-24 至 04-30 中不满足尺度条件的日子，即五个检测通道中任何一个的宽度倍数超过 3.0；宽度倍数 = 当日 P10–P90
   宽度 ÷ 参照期宽度，取自 `docs/m3_marapr/daily_channel_profile_ref0308.csv`（与 `v34_daily.csv` 的计算相同）。逐台给出这些日子上
   确认事件（按确认时刻所在的日子）的条数与 F、T 构成。敏感性列：气体宽度倍数不低于 1.5 的日子，做同样的统计（10 月 19 日裁决书第六点）。
   交接文档写的是「气体宽度倍数超过门槛的日子」，裁决书写的是「不满足尺度条件」（五个通道任一）；主表按裁决书，同时注明超标的通道。
4. **C 的日照直射与傍晚气体上升**：日照直射段取 `docs/m3_inject/c_alarm/evidence.md` 条件甲中 C 有告警窗口的五天（04-17、04-20、
   04-21、04-24、04-25）的世界协调时 11 至 14 时，只看设备 C；傍晚气体上升段取 04-17 世界协调时 18 至 24 时，八台都看。逐段给出
   是否有归属于它的候选与确认。
5. **盲区**：每个候选之后，到其后第 30 个元素为止（检测器重新攒够 30 个元素之前）为盲区。对第 2、3、4、7 条中的每一段，若它与某个盲区
   重叠，而且没有任何候选归属于它，就记为「盲区内错过」。
6. **基线对照**：基线候选的逐台总数，以及它对第 2、3、4、7 条各段的命中（按第二节的归属规则，基线没有确认，只看候选）。
7. **异常不得被确认为漂移**：在不剔除注入的元素流上运行，对设备 E 的十四段注入（`docs/m3_a4/full_fix/inject-truth.csv`）逐段给出
   是否有归属于它的候选、是否有确认。六小时爬坡与 K = 36（十分钟粒度）恰好相等，是边界情形。

## 四、参数选择规则的操作化

交接文档：只有当默认组合（置信度 0.99、鲁棒度 0.5、十分钟粒度、K = 36）在第 1 条上的误漂移数明显高于某个邻近组合，并且在第 2、3 条上
不比它差时，才更换。本文的操作化（由代码开发 agent 拟定，请设计会话在看结果之前确认或修改）：

- **邻近组合**：与默认组合只差一个参数的组合共 6 个：置信度 0.999；鲁棒度 0.3；鲁棒度 0.1；小时粒度；K = 18；K = 72。其中鲁棒度 0.1
  按 0.92 版第三点会使切点机制失效，只列出、不作为更换候选，所以更换候选是其余 5 个。
- **明显高于**：默认组合在第 1 条上的机队总数比邻近组合多出至少 50%，并且至少多 3 条。
- **第 2 条不比它差**：三月尾段有确认的设备数不少于默认组合。
- **第 3 条不比它差**：有确认的尺度漂移日（按设备日计）不少于默认组合。
- 满足以上三条的邻近组合不止一个时，不自动选择，列出交给设计会话。

无论换与不换，报告都附上 36 种组合与基线的完整表格。
