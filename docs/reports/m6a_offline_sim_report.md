## 七、判读口径第五条：上下文通道（已按做法甲完成，结果见第十一节）

这一条要量的是「输入换了标准化之后，模型是否仍然适用」：用同一个上下文模型，分别给命令前一天与命令后的标准化轮评分，比较主分分布。它需要一个上下文模型，而轮表与本报告的工具里都没有：全量运行训练出的模型只存在于当时作业的状态里，没有导出。

可选做法：

| 做法 | 内容 | 代价 |
| --- | --- | --- |
| 甲：离线训练（建议） | 用已有的离线训练工具 `com.leejean.m3.M3Grid`，按全量运行的参数，在模拟器导出的旧参数标准化轮上训练 G 与 B 的模型；再给命令前一天与命令后、新参数下的轮评分 | 不用集群，在开发机上运行；工作量是写一个导出与评分的小工具。模型与全量运行的不是同一个（训练有随机性），但训练口径相同 |

## 八、复现方式

- **执行环境**：开发机或本地 Mac，仓库根目录；JDK 11、python3.9 及以上；先执行 `mvn package`。
- **调用命令**：
  ```bash
  CP=target/iot-anomaly-detection-1.0-SNAPSHOT.jar
  for spec in "G 2022-03-25 1.5" "B 2022-03-16 1.0"; do set -- $spec
    java -cp $CP com.leejean.m6.M6aSimulator --rounds docs/m6a/extract/rounds_$1.csv.gz --device $1 --r $3 --tag $1_off
    for D in 1 3 7; do
      java -cp $CP com.leejean.m6.M6aSimulator --rounds docs/m6a/extract/rounds_$1.csv.gz --device $1 --r $3 --day $2 --reestimate-days $D --tag $1_on_D$D
      python3 m6a/reestimate.py --rounds docs/m6a/extract/rounds_$1.csv.gz --device $1 --day $2 --reestimate-days $D --out docs/m6a/sim/$1_D${D}_py.json
      java -cp $CP com.leejean.m6.M6aOfflineRunner --rounds docs/m6a/extract/rounds_$1.csv.gz --device $1 --day $2 --reestimate-days $D --out docs/m6a/sim/$1_D${D}_java.json
      python3 m6a/compare.py docs/m6a/sim/$1_D${D}_py.json docs/m6a/sim/$1_D${D}_java.json
    done
    java -cp $CP com.leejean.m6.M6aSimulator --rounds docs/m6a/extract/rounds_$1.csv.gz --device $1 --r $3 --day $2 --exclude-outliers docs/m6a/sim/$1_off_outliers.txt --tag $1_onx_D1
  done
  python3 m6a/sim_report.py
  ```
- **前置条件**：轮表在库。
- **期望产出**：`docs/m6a/sim/` 下每次运行的逐日、逐小时与事件表，六份比较都打印「逐位相同」，以及 `tables.md`。
- **常见失败**：如果模拟器报「不足以冻结」，说明轮表不完整，请重新运行 `eda/m6a_extract.py`。

## 十、1.30 版裁决之后的补充（2026-11-05）

**第三项：G 光照多日 D 统计量完全相同。** 按裁决先在理论层核对机理假设，结论是假设成立。在取到最大差的那条箱边上，当天读数全部落在边的同一侧，所以 D 等于参照在这条边上的累积质量，与当天读数的具体分布无关。

| 运行与日期 | 取到最大差的箱边（log1p 域 / 光照原值） | 当日在边以下的质量 | 参照在边以下的累积质量 | D |
| --- | --- | --- | --- | --- |
| 有命令（参照取自 03-24 一天）：04-23、04-24、04-29、04-30、05-01 | 5.983936 / 396 | 0（当日最小值约 1,265） | 0.610453 | 0.610453 |
| 无命令（冻结参照）：04-02、04-15、04-16、04-17、04-18、04-19、04-21 | 7.140453 / 1261 | 1（当日全部不高于 1,261） | 0.180035 | 1 − 0.180035 = 0.819965 |

- 对照：有命令时的 03-26，当日在 396 以下的质量为 0.061179，所以 D = 0.549273，没有饱和。
- 按裁决，这记为统计量的性质（D 饱和于参照的箱边质量），不是数据异常，并作为交接文档中「分箱 D 的误差上界为单箱质量」一条的实例。
- 只记录一条事实，不下结论：有命令运行中饱和的五个日，G 的光照全天不低于约 1,265（原值）。
