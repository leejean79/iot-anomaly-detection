## 一、结论摘要

1. **丁档的四项数量预期全部相符。** 命令总数 23（甲 60，预期低于 54）；七天内丙型实例 5（甲 11，预期不多于 5）；非触发通道连带偏离日数 165（甲 364，预期不高于 364）；从进入偏离到生效的典型延迟 168 小时（甲 72 小时，预期 144 至 192 小时）。生效前回落而撤销的命令 24 条。按写定的选定判据，命令总数与连带偏离日数两项都指向丁。
2. **首条命令时刻的三项中有两项不符。** 气体抬高相符。三月事件不符：D 与 G 在丁档中 03-20、03-21 就已决定（温度、气体），03-26、03-27 生效，推迟期间冷却挡住了 03-22 至 03-27 的新决定，按写定规则记为「无」。G 光照不符：03-11 至 03-12 的光照偏离在 03-13 回落，命令撤销。
3. **振荡规则（只认生效之后的回落）。** 加在甲上：命令 60 降为 54、首条不变，相符；连锁丙型实例由 8 降为 3，未归零，剩下的 3 例（A、B、F 的温度）都在第二条生效之后回落（A 04-11、B 04-11、F 04-08）后解除，属于裁决允许的情形，按裁决列出。E 温度与 H 光照两例按新口径已被抑制。加在丁上：连锁丙型实例由 2 降为 0，相符；但命令总数仍为 23，不符——A 与 D 的温度第三条在 04-13 起被抑制，通道一直偏离，抑制在十四天或回落后解除时照发（D 04-18、A 04-21），所以是推迟而不是消失。
4. **核对。** 丁档与丁档加振荡共 46 条执行的命令，Java 与 Python 新参数逐位相同（光照最大差 8.9e-16，`docs/m6c/chain/check_ding.md`）；各档同一配置运行两次逐字节相同；全部开关关闭时链式基线与第二批收口逐字节相同；乙、丙两档的输出与上次运行逐字节相同（推迟与振荡改动不影响它们）。

## 二、实现

- **聚合模块。** 参数 `deferDays`（链式 `--anchor-defer-days`，在线 `--m7-anchor-defer-days`，0 为关闭）。零级的生效取「决定后一日界」与「最早进入之日加 deferDays 的日界」中较晚者；需要推迟时命令留在聚合模块内，到生效前一个日界才发出，序号在发出时给（撤销的命令不占序号），推迟期间该台的零级冷却到生效后一日。每个日界先检查触发通道：已回落（与「同一段只发一次」的回落同一定义：日界可判且不偏离）的通道去掉，复核写「零级推迟中：部分触发通道回落」；数据层触发通道全部回落时撤销，复核写「零级撤销：生效前回落」并解除冷却。
- **振荡规则的回落口径。** 只认布下抑制的那条零级生效当日及之后的 RECOVER（1.56 版裁决第二项）；十四天取两条决定时刻之差、部分通道被抑制时其余照发（第三项确认）。
- **标准化算子侧。** 丁档用 `--anchor trigger --anchor-min-days 7`；推迟之后锚定窗口恰为七天。
- **单元测试。** `FleetBatch3Test` 增加推迟与撤销的用例（决定日不变、生效为进入之日加七天、撤销后不占序号、回落后可再决定），振荡用例改为「生效前回落不解除、生效后回落解除」。

## 五、需要上报设计会话的事项与后续顺序

需要设计会话裁决的事项如下，用户无需执行任何步骤：

1. **默认值：甲还是丁，以及振荡规则开不开。** 写定判据指向丁（命令 23 对 60，连带偏离日 165 对 364），代价是典型延迟由 72 小时升到 168 小时、漂移告警由 1,355 升到 3,677。振荡规则在甲上使命令再降 6 条，在丁上只推迟两条、不减少。
2. **首条时刻两项不符的认定。** 三月事件的 D、G 在 03-20、03-21 即已决定（03-26、03-27 生效），G 光照因 03-13 回落而撤销；这是写定规则的时段边界与实际时序的差别，代码层已核对（单元测试、跨语言逐位）。
3. **推迟期间部分触发通道回落时去掉该通道、其余照发（5 条），请确认。**
4. **甲的典型延迟 72 小时与裁决所写 48 小时的口径差别，请确认按哪一口径登记。**

先后关系：
- 推迟生效与新的振荡口径都在聚合模块的同一个类里，在线作业直接用同一份代码（参数 `--m7-anchor-defer-days`、`--m7-osc-suppress`，标准化算子 `--adapt-anchor trigger --adapt-anchor-min-days 7`），在线实现已经完成、默认关闭。
- 第一组短重放（第三批全部开关关闭时，新代码与标签 jar 逐位相同）不依赖以上裁决，我接着编写集群脚本。
- 第二组短重放（开启选定项后两次运行逐位相同）要等第 1 项裁决定下开启哪些项。

## 六、复现

- **执行环境**：开发机或本地 Mac，仓库根目录，JDK 11，python3.9 及以上。
- **调用命令**：
  ```bash
  mvn -o compile
  CP="target/classes:$(cat target/test-cp.txt)"
  B="--variant D7 --keep-channels Humidity,Pressure"
  D="--anchor trigger --anchor-min-days 7 --anchor-defer-days 7"
  java -Xmx6g -cp "$CP" com.leejean.m6.ChainDriver $B $D --out-dir docs/m6c/chain/ding
  java -Xmx6g -cp "$CP" com.leejean.m6.ChainDriver $B --osc-suppress true --out-dir docs/m6c/chain/off_osc
  java -Xmx6g -cp "$CP" com.leejean.m6.ChainDriver $B $D --osc-suppress true --out-dir docs/m6c/chain/ding_osc
  python3 m6b/chain_check.py --chain-dir docs/m6c/chain --variants ding,ding_osc --out docs/m6c/chain/check_ding.md
  python3 m6c/chain_anchor_report.py --ding-arm ding --osc off_osc:off,ding_osc:ding
  ```
- **前置条件**：同第 2 步报告（八台轮表、E 的注入轮表、`docs/m7/inputs`、`target/test-cp.txt`），并已运行 off、trigger、all 三档。
- **期望产出**：每档约半分钟；`chain_check.py` 退出码为零；判定表与本报告数字一致。
- **常见失败**：同第 2 步报告。
