# 设备 G 光照通道的全程逐日剖面（0.89 版裁决第三节）

本报告只报事实，不下结论；成因由设计会话结合随数据集发布的材料判定。由 `eda/g_light_profile.py` 从原始 CSV 生成（读入含光照读数的文件 3471 个，按设备与时间去重后 9899240 条读数）。

## 〇、口径

- 日期与小时一律为布里斯托当地时间（`Europe/London`）：2022-03-27 01:00 UTC 之前为世界协调时，之后为世界协调时加一小时。
- 「白天减夜间」= 当地 11 至 14 时读数的中位数减去当地 0 至 3 时读数的中位数。
- 底值集合取自 `docs/stuck_guard/floor_values.csv`（G 的光照为 1、2、10、14）；「底值占比」是当日读数落在该台底值集合内的比例。
- 游程：值不变且相邻读数间隔不超过 60 秒（与守卫一致）；跨午夜的游程计入起始那一天。
- 描述性状态标记（只是标记，不是结论）：底值占比不低于 50% 记「底值为主」；否则若中位数高于该台底值集合的最大值、且 P10 至 P90 宽度不超过中位数的 10%，记「近乎恒定」；其余记「有日内变化」。
- 「复制段」指 `docs/copy_segments.csv` 中六月复制的目标日期，那几天的数据是复制来的。
