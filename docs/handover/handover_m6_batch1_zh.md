## 第零节：五项设计决定（已确认）

**决定八：命令回路经 Kafka 命令主题回到上游。** 数据接入模块的标准化算子按设备键连接命令主题 `synergia-adapt`（10 月 28 日更正：窗口算子不能连接第二路输入，所以第一批只有数据接入模块连接命令流，版本号与回填附件随标准化轮下发到点通道与上下文模块）；命令存入受检查点保护的状态，在事件时间到达生效时刻时执行；执行之后的输出携带参数版本号；在生效时刻之后才到达的命令记为迟到并计数，"迟到命令数为零"加入重放完整性断言（第八条），由数据接入模块计数。

**决定九：原始缓存改为紧凑格式、深度七天。** 每轮五个单精度数加时间戳与掩码，约两兆每台，受检查点保护；深度参数化，默认七天。

**决定十：零级的执行定义。** 数据接入模块用缓存中生效时刻之前最近 D 天（默认一天，参数）的轮重估五个通道的中位数与四分位距，重估窗口剔除守卫打标的轮；换版本后用同一窗口重新冻结数据层的参照直方图并附在第一条新版本轮上；点通道清空状态、从缓存按新参数回填一个窗口；上下文模块的模型与阈值不动，只在输出上换版本号；零级之后一天冷却期（冷却期由聚合模块执行，本模块只记录）。

**决定十一：第一批的验收。** 单元测试；离线模拟（G 的光照与气体抬高两个用例）；短重放等值（手工下发同一条命令，在线执行与离线模拟逐位相同，迟到命令为零）；性能（缓存状态大小、回填耗时）。

**决定十二：第二批的范围预告。** 一级（热启动、最近 N 天净化样本、旧模型继续服务、原子切换）、二级（回收集态并重新冻结）、开放问题第十二条的实验、决策矩阵中一级与二级的格子、全量重放。本阶段不做。

## 第一节：任务的一句话说明

让一条带生效事件时间的零级命令能够从命令主题进入三个上游算子，在事件时间到达生效时刻时由数据接入模块重估标准化参数并换版本、重新冻结数据层参照、由点异常检测模块重建状态、由上下文模块换版本号，整个过程在两次运行间逐位相同，迟到命令为零。

回路的下半段（聚合模块发命令）在另一份交接文档里；本阶段做的是上半段：命令主题、三个算子对命令的消费、生效时刻的执行。

![零级的含义](figs/m6_l0_explained.png)

零级靠重估中位数与四分位距把位置平移与尺度伸缩映回模型学过的标准化分布；它对分布形状的变化无效，这一局限由聚合模块的"不回落则升级"处理，留待第二批。

![命令的确定性](figs/m6_command_determinism.png)

命令经 Kafka 回到上游的到达时刻是非确定的；只有把执行锚定在生效事件时间上，两次运行才能逐位相同。

## 第三节：命令契约

命令主题 `synergia-adapt`，一个分区，键为设备号。每条命令的字段与含义如下表。

| 字段 | 含义 |
|---|---|
| 设备号 | 命令作用的设备。 |
| 级别 | 本阶段只有零级；字段保留一级与二级的取值供第二批使用，收到非零级命令时本阶段记录并忽略。 |
| 生效事件时间 | 算子在事件时间到达这一时刻时执行命令；它必须晚于决定时刻。 |
| 决定时刻 | 聚合模块做出决定的事件时间。 |
| 命令序号 | 聚合模块按设备维护的序号，从一起计；数据接入模块执行后取"序号加一"作为新的参数版本号（冻结时版本号为一，第一条命令执行后为二；10 月 28 日选定）。 |
| 决定依据 | 触发事件的引用、同报设备数、范围、归因标签、时间形态；本模块原样写入执行日志，不解释。 |

手工验收时，命令由一个小工具写入命令主题，字段与上表相同。

## 第四节：各算子的改动（10 月 28 日按裁决书改写）

**算子顺序。** 作业中原来的顺序是对齐事件时间、标准化、原始缓存，守卫打标在原始缓存算子里计算，位于标准化之后。本阶段把原始缓存算子移到标准化算子之前，守卫与冷启动标记先写到轮上；原来那个只写不读的一千轮环形缓冲删除。两个算子互不依赖，调换顺序后的输出逐位不变，由"命令回路关闭时逐位相同"的验收直接证明。

**标准化算子（数据接入模块）。** 其一，紧凑环形缓冲放在这里：每轮五个原始读数（光照为 log1p 之前的原始值，删失标记在掩码里）、事件时间戳、守卫掩码；存储精度由提取脚本的统计决定——各通道不能被单精度精确表示的读数数全部为零则用单精度（每台约两兆），否则用双精度（每台约四兆）；深度七天（参数）；受检查点保护，序列化只写已用部分。其二，连接命令流：命令源发出最大水位线，命令流不参与水位线计算；命令到达时若生效时刻不晚于数据流的当前水位线则记为迟到并计数，否则存入状态并注册生效时刻的事件时间定时器。其三，定时器触发时执行零级：取缓存中生效时刻之前最近 D 天（默认一天）的轮，剔除守卫打标的轮，按与冻结相同的函数重估五个通道的中位数与四分位距（光照在 log1p 域，删失值不计入）；版本号换为命令序号加一；用同一窗口按数据层阶段的做法重新生成参照直方图；把生效时刻之前一个窗长（一小时）的轮按新参数标准化后作为回填附件；参照直方图与回填附件都附在第一条新版本轮上下发（与数据层阶段参照直方图同一机制）；此后输出的标准化轮携带新版本号。其四，执行日志：每条命令的到达事件时间、生效时刻、是否迟到、重估窗口的轮数与剔除数、新旧参数、新版本号。

重估窗口与冻结的取样规则不同：冻结按轮数取且不剔除守卫轮（冻结时守卫标记尚不存在），零级按时间取且剔除守卫轮；两者共用同一个计算函数，差别只记录，不改冻结，并登记为理论回传待办。

关于剔除点通道标记为离群的轮：理论第十四条协议要求重估前做训练集异常剔除。标准化算子在上游，拿不到点通道的离群标志；本阶段只剔除守卫打标的轮，依据是中位数与四分位距对百分之几的离群轮稳健。离线模拟中另算一遍剔除离群轮的版本并与在线定义并排（判读口径第四条），若两者差异超过逐位等值方法手册里"同一实现"的容差，这一条带回设计会话。

**点异常检测模块。** 不连接命令流。版本号沿现有路径从标准化轮传到点通道的点。滑动步内新到的点带有与该台当前版本不同的版本号时，与冷启动同一处清空该台的 MCOD 状态，再用该点所携带的回填附件回填一个窗长：回填的点只用来建立邻居关系，不发出判定（它们的判定早已发出）；回填完成后的第一条新轮起正常判定，离群记录携带版本号。

**上下文异常检测模块。** 不连接命令流，模型、阈值、窗口、相位都不动；从标注轮读版本号带到评分输出上。一级与二级在第二批要改它的算子，到时再连接命令流。

**数据层漂移监测模块。** 不连接命令流；从第一条新版本轮的附件里拿到新参照直方图，替换参照、清空状态转移状态与当日缓冲，不发回落事件，从该轮所在当地日重新开始；日记录与事件带版本号，聚合模块由版本号得知参照已重置。生效时刻不在当地日界时，生效当日记为"重估日"，与标定日一样不可判（聚合模块的命令生效时刻都在日界上，这种情形只出现在手工命令里）。性能层模块不改。

**断言。** 重放完整性断言加第八条：迟到命令数为零，由标准化算子计数。

**版本号字段。** 在标准化轮、点通道离群记录、上下文评分、日记录与数据层事件上都是可空字段；命令回路关闭时为空且不写进 JSON，各主题输出与改动前逐字节相同。

**参数。** 缓存深度、缓存精度、重估窗口 D、命令回路总开关。

## 第五节：离线模拟

**工具。** Python 参考实现读原始数据、冻结参数与一条手工命令，按第四节的定义算出新参数、新参照直方图与回填窗口；再用数据层阶段的离线工具在新参照上重算命令之后的数据层状态转移，用点通道离线探针在新参数上重算命令之后的离群率。Java 离线运行器共用在线的重估函数，与 Python 逐位比较（中位数与四分位距的计算没有超越函数，不设容差）。

**两个用例。** 其一，G 的光照：标定窗口被连续人工照明污染（数据事实第三十四条），数据层光照通道自冻结起持续偏离；离线模拟在全量数据与标定周参照上做，手工命令取生效时刻为三月二十五日的当地日界。短重放的参照是三月二十四日这一天而不是标定周，复现不了这一污染，所以短重放的手工命令另取时刻（验收项三）。其二，气体抬高：B 的气体自三月十四日起相对标定周抬高（第三十六条候选）；手工命令取生效时刻为三月十六日的当地日界。

**判读口径**（运行前写定，均为测量项）：

1. 重估前后五个通道的中位数与四分位距，并与标定周的值并排；重估窗口的轮数与剔除数。
2. 命令之后数据层该通道的状态：G 的光照是否在新参照上回到正常并保持；B 的气体是否回到正常，以及三月二十二日事件到来时是否重新进入偏离（这是"零级之后数据层仍能看见下一次漂移"的检验）。
3. 命令之后点通道的离群率：与命令之前一天、与不执行命令的同一天并排；回填窗口结束后第一小时的离群率单独列出（状态重建的瞬态）。
4. 剔除离群轮与只剔除守卫轮两种重估的参数差，以及由此引起的离群率差。
5. 理论第二条风险的检验：上下文通道在命令之后的主分分布（中位数、第九十五百分位、超阈率）与命令之前一天并排；注入段若落在命令之后，列出召回表的变化。模型不动，这一条量的是"输入换了标准化之后模型是否仍然适用"。
6. 重估窗口 D 取一天、三天、七天时第一、二条的变化（只作记录，不改默认）。

## 第六节：验收标准

- 验收项一（V-M6a-1）：单元测试全部通过；命令回路关闭时（含算子顺序调换后）四个模块的全部输出与改动前逐位相同；Java 重估函数与 Python 逐位相同；迟到判定、定时器、回填不发判定、版本号传递各有用例。
- 验收项二（V-M6a-2）：离线模拟报告，六条判读口径逐条填写。
- 验收项三（V-M6a-3）：步骤 C 规模的短重放（三月二十四日至三十一日，与聚合模块共用区间）上对 G 手工下发一条生效时刻为三月二十八日当地日界的零级命令（G 在该区间内三月二十五日冻结，命令须在冻结之后）：在线的新参数、新参照直方图、命令后的标准化轮、点通道判定、数据层日记录与离线模拟逐位或逐条相同；迟到命令为零；两次在线运行逐位相同。
- 验收项四（V-M6a-4）：性能：缓存状态大小（每台与总计）、检查点体积增量、回填耗时、重估耗时。
