## 第一项：时段四的起点前移到四月十四日

**裁定：前移。** "起点以最早一层为准"是一条一般规则，不因有无机队级爆发而改变；时段四的数据层证据是六台气体在四月十四日进入偏离，分辨率是一天，所以起点记为"四月十四日（日分辨率）"，与时段一的"四月二日十三时（爆发时刻）"在表里注明分辨率不同。A、B、D、F、G 五个气体触发改为长瞬态实例候选，条件仍是偏离段在时段结束后回落，请补回落日期。补充二的长瞬态实例候选由十二个增为十七个（若五个都回落）。

## 第二项：六十一个现场条件小时的性质

清单显示这六十一个小时不是一种东西，而是三种，登记为数据事实第三十八条候选，规则不改。

**第一种，局部的周期性现场因素，即这个标签原本要捕的东西。** D 在三月三十一日至四月九日的十四至十五时，温度正向偏离零点五到二点一个参照宽度，部分伴随光照——这是 D 所在位置午后的周期性受热（日照或供暖），与 C 正午日照直射同一性质而且更规律，是本数据上"现场条件"的真正实例；C 自己的正午反而因为处在温度漂移期而没有被标到，这是开环的覆盖效应。G 在七天的六时整有点通道标志并伴随气体，也是局部的、按时刻重复的因素（六时附近 G 周围有某个每日动作，成因不在数据里）。

**第二种，全场性的、按时段重复的气体抬升，低于当日的共模门槛。** 四月八日四至九时 B、D、E、F、G 五台共十八个小时，气体正向一点七到四点九个宽度；E 在四月三日、八日、十日、十一日的凌晨与晚间；H 在四月二十五、二十六日的十九至二十三时。这些小时之所以被标为现场条件，是因为规则只要求"同一钟点最近七天里有标志"与"同步变化"，没有要求当日的标志是局部的；五台同报低于八台的四分之三门槛，于是按局部处理。它们的性质与数据事实第三十五条候选的五个共模时段相同（全场气体抬升后回落），并且揭示了一个此前没有写明的结构：四月的共模气体抬升集中在凌晨（零时至九时：时段一、时段三、四月八日）与傍晚到夜间（十六时至二十三时：时段四、傍晚气体上升、H 与 E 的晚间小时）两个时段，有日内周期。这一条写进第三十五条候选的补充。

**第三种，零散的单次小时**（C 的四个气体小时与一个负向光照小时等），数量不足以归类，只记录。

两点带回设计：其一，"现场条件"标签需要一个范围维度——局部周期与全场周期是两件事，前者归一级重训处理，后者是环境节律，应当进上下文模型的输入或作为告警抑制的依据；其二，"同步变化"在气体引起标志时等于用气体自己佐证自己，这一条件对气体是弱的。两点都登记为理论回传第二十五条，不在本阶段改规则。

## 第三项：扫描说明的更正

**接受。** C 四月十日的确认段满六小时的时刻与回落之间没有决策节拍，是节拍对齐的结果，没有规则挡它；上一份裁决书"被冷却期或同一段偏离挡住"的说法改为"两段被冷却期挡住、一段落在节拍之间"。

## 第四项：三月三十日缺口的数据事实

**裁定：按补充五登记为数据事实第三十七条候选，措辞"约一小时"。** 三月三十日约十九时十二分至二十时十二分（世界协调时）原始数据集八台同时无读数约一小时，自述文件无说明；二十时十二分恢复后八分钟机队级爆发的报警元素出现。成因的判定：点通道的滑动窗在一小时缺口期间排空，恢复后的首批轮在窗内邻居不足而被判为离群，爆发是缺口的产物而不是数据的异常；这一判定的依据是窗长恰为一小时、八台同时、爆发紧随恢复。数据层阶段的待核实项关闭。缺口起点的直接证据等用户重跑 `gap_check.py` 后补入，不阻塞登记。
