## 第一节：两处提取缺陷的处置

**裁定：修正后的提取成为数据层与聚合模块离线输入的新基线，重跑并更正已收口文件，开发设计日志记一笔更正。** 判据是 1.30 版第五项：缺陷二改变了已进入数据层阶段报告的计数——离群率爆发次数由 245 / 247 变为 248 / 250（多出的三次都在 C，三月十日与十一日，冻结后两天内），由它引出的对照计数 106 变 109、90 变 93；"零确认"的结论不变。其余变化都在末位或中间量，聚合模块的命令、复核、时间参数扫描与时延表完全相同，只有一条告警的爆发标志字段与一处表格数值变化。

处置细节：
1. `docs/m5a/extract_fix/` 与 `docs/m7/extract_fix/` 转正为 `docs/m5a/extract/` 与 `docs/m7/extract/`，旧基线改名保留（`extract_v1/`），不删除；下游的数据层离线实验、聚合模块输入准备、十一种配置、十二种扫描、时延表按默认目录重跑一次，产物覆盖；Java 离线运行器与 Python 参考实现在二十三种配置上的逐条相同重做一遍（两边读同一份输入，预期不变，但要留证据）。
2. 数据层阶段报告、待决事项文档与离线报告中引用 245 / 247、106、90 的句子，由代码开发 agent 在文末加"更正（2026 年 11 月 7 日）"一节注明新值与来源，不改正文。
3. 这两处缺陷都停在排查次序的第一层（代码），不是数据事实。但有一个方法上的教训写进逐位等值方法手册：**文本到浮点的解析也是实现的一部分**，跨语言比较时两边都必须用正确舍入的解析器（Java 的 `Double.parseDouble`、Python 的 `float`），pandas 的默认 C 解析器不保证正确舍入，本数据约百分之八的温度与湿度读数会差最后一位；以及**成轮规则必须与在线成轮器一致**，只有质量通道读数的时间戳也是一轮，否则冻结时刻差一到两轮、参照直方图随之不同。
4. 缺陷二的另一个意义：离线提取与在线运行不一致时，在线是基准，离线向在线对齐；这次正是在线的点通道离群轮数暴露了离线的冻结差一轮。写入"离线与在线等值"约定的说明。

## 第二节：G 光照多日 D 统计量相同的机理

**裁定：假设成立，记为统计量的性质。** 在取到最大差的箱边上当天读数全部落在同一侧，D 等于参照在该边上的累积质量，与当天分布无关：有命令运行中五个日的 D 为 0.610453（当天最小值约一千二百六十五，高于边值三百九十六），无命令运行中七个日的 D 为 0.819965（当天全部不高于一千二百六十一）。写入交接文档"分箱 D 的误差上界为单箱质量"一条的实例，并作为数据层方法的一个已知性质登记：**当某日分布整体越过参照的某条箱边时，D 饱和于该边的累积质量，不再反映偏离的幅度**；幅度要看逐日位置统计量（偏移倍数），这正是数据层第二族信号存在的理由。

## 第三节：上下文通道在零级之后的失配（判读口径第五条）

这是适应执行第一批最重要的结果，登记为**数据事实第四十条候选**与**理论回传第二十七条**。

**事实。** 用与全量运行同一口径离线训练的模型（两个种子），命令后七天的入口轮用零级之后的新参数（D 取一天）标准化再评分，超阈率 G 为 76.7% 与 88.5%、B 为 82.0% 与 83.3%，主分中位数 G 约二十七到三十一、B 约十一到十二；同样的轮用冻结参数标准化时超阈率只有 G 7.5% 与 6.1%、B 1.9% 与 0.5%。两个种子之间各格的差在十九个百分点以内，新旧参数之间的差别方向在两个种子上一致。

**判断。** 上下文模型绑定于训练时的标准化坐标：它学的是"用冻结参数标准化之后的输入"。零级把标准化参数换掉，等于把模型的输入换到另一套坐标；只有当新参数恰好是漂移的逆（位置平移多少就把中位数挪多少、尺度不变）时，换坐标才把数据映回模型见过的分布。本次用一天窗口重估，湿度与气压的四分位距缩到冻结时的五分之一到十二分之一（数据事实第三十九条候选），这两个通道的标准化值被放大五到十二倍，日内的正常波动在模型眼里全是极端值——示意图中间一幅。所以这个结果主要是 D 取一天的后果，但它暴露了更一般的问题：**理论文档把零级写成"仅重估标准化统计量、模型不动、先行观察误差是否回落"，隐含的前提是重估恰好抵消漂移；前提不成立时，零级不是温和的先行动作，而是直接破坏上下文通道。**

**本批补做两档，运行前写定预期（不迎合：结果是什么记什么）。** 其一，D 取七天：湿度与气压的尺度接近冻结值，预期命令后七天新参数的超阈率大幅回落，但 G 光照（分母由 0.079 变 4.15）与气体（位置大幅变化）仍会使 G 的超阈率明显高于旧参数那一格；其二，只重估位置（中位数取 D 为七天，分母保留冻结值）：预期两台的超阈率回到旧参数一格的量级，G 光照除外（它的问题是尺度被污染，只挪位置救不了）。两档都用种子 42 与 7，表格与第十一节同式。这两档不改默认值，是给理论线的证据。

**带回理论线的设计问题（第二十七条）。** 三个选项由理论线裁决：
1. 上下文通道不跟随零级：上下文模块用训练时的参数版本标准化自己的输入（数据接入模块下发原始值与各版本参数，或上下文模块自存训练版本的参数），只在一级或二级重训时换版本；零级只作用于点通道与数据层。这样零级对上下文通道无害，但也无益——位置平移式的漂移对上下文通道只能靠一级。
2. 零级只重估位置、保留尺度，尺度的重估只在数据层报告尺度漂移时做；并且重估窗口不短于七天。这保留了"零级先行"的设想，前提是本批第二档的实测支持它。
3. 零级之后对上下文通道加一次"阈值重标定"（用重估窗口上的新主分重算评分器的中位数与四分位距），模型权重不动。这是最便宜的折中，但等于承认零级之后旧阈值作废。

**验收状态。** 验收项二以"六条判读口径均已填写"为准，通过；第一批的收口等上述两档补做与短重放、性能两项验收完成后一并出具。
