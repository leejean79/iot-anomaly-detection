## 第零节：设计决定（已确认）

**决定十三：上下文通道不跟随零级（理论回传第二十七条第一个选项，用户 11 月 8 日裁定，全量重放时再验证一次）。** 上下文模块保存训练完成时的参数集（五个中位数、五个分母、旁路标志），此后从轮上的原始值自己按训练版本标准化，评分输出的版本号为训练版本；只在一级或二级重训切换时改取当前版本的参数集。数据接入模块在每个版本的第一条轮上附参数集（与参照直方图同一机制，冻结时也附）。全量重放中上下文模块另做影子评分：同一模型按当前版本的标准化再评分一次，只记录每台每小时的影子超阈率，不进性能层、不进聚合模块；这是用户要求的"再验证一下"，判据写在第七节。

**决定十四：聚合模块按参数版本过滤日结论。** 引用之前日界的数据层结论时，只引用与该台当前版本相同的结论；性能层与上下文通道的版本是训练版本，与零级无关，不过滤。补完后在开环默认配置上重跑，三份日志应与聚合模块收口时逐条相同（开环无版本变化）。

**决定十五：链式离线实验先于一切在线工作。** 范围与判读见第四节。零级的重估窗口以 D 取一天、七天与"只重估位置（中位数七天、分母冻结）"三档作对照，默认值在链式实验之后由设计会话按预写判据选定，之后一级与二级的开发与全量重放都用选定值。

**决定十六：决策矩阵的升级格按选项一的后果改写。** 零级不再触及上下文通道，所以理论矩阵"缓变退化：零级先行、误差不回落则二级"这一行在本装配中失去前半段——零级不可能让上下文模型的误差回落。改写为：只有性能层持续，直接一级；一级之后 K_up 天（默认七天，参数）内性能层再次确认，二级。两层同报，一级（理论原文）。只有数据层持续，零级；零级之后 K_up 天内同一通道再次持续，一级。这一改写登记为理论回传第二十八条。

**决定十七：一级与二级的定义。** 一级：该台上下文模型热启动重训（从当前权重出发），训练集为最近 N 天的入口轮按当前版本标准化、剔除含点通道离群轮的窗口，早停集与标定集按比例从同一段尾部划出（训练、早停、标定按七比二比七的比例压缩到 N 天内），旧模型继续服务直至新模型标定完成，原子切换，切换时取当前版本参数集，输出版本号改为新训练版本。N 与热冷启动由开放问题第十二条的实验选定（第五节），实验前默认 N 取七天、热启动。二级：该台上下文模块回到收集态，按首次训练的数据段（七天训练、两天早停、七天标定）从头训练，期间该台上下文通道与性能层静默、数据层与点通道照常（理论风险一的缓解）。两级都复用补遗四的异步训练机制（算子内执行器、不可变快照、结果槽、有界缓冲、排空期间水位线保持）。

**决定十八：一次全量重放闭环运行。** 一百五十倍速，有限重启三次，全部模块与命令回路、聚合模块打开，断言八条全部成立；等值判据见第七节。

## 第三节：第一项——聚合模块按版本过滤（决定十四）

**改动。** 聚合模块的输入映射读日记录与数据层事件的版本号；小时节拍的数据层标志与日节拍的三条持续规则只引用与该台当前版本相同的日结论；"同一段偏离"的段在版本变化时随数据层状态清零而结束（这与闭环里"参照重冻则段结束"一致，不再需要"只发一次"规则替代，但规则保留，作用于同一版本内）。Python 参考实现同步。

**验收（V-M6b-1）。** 单元测试：跨版本的日结论被忽略、段在版本变化时结束；开环默认配置重跑，告警、命令、复核三份日志与聚合模块收口时逐条相同；二十三种配置的 Java 与 Python 逐条相同重做。

## 第四节：第二项——链式离线实验（决定十五）

**原理。** 在选项一下，零级不改变上下文通道的输入，所以全量运行留下的上下文主分与性能层事件在链式实验里原样可用；需要随命令重算的只有数据接入的参数与参照、点通道的判定、数据层的状态与日记录，以及聚合模块的决策。这使链式实验不需要训练任何模型。

**驱动。** 一个按当地日推进的驱动程序：第 D 日日界，聚合模块的决策函数读到当日为止的全部输入（点通道离群记录、上下文主分、性能层事件、数据层日记录与事件、质量信号、小时均值）产出命令；命令按生效时刻（下一日界）交给八台的模拟器；模拟器执行零级（重估、换版本、新参照、点通道回填）并继续逐轮推进到下一日界，产出新的离群记录与日记录；驱动把它们追加进输入，再进入下一日。全部八台都要有轮表（`eda/m6a_extract.py` 对八台各提取一次，由用户在 Mac 上运行；轮表约八个压缩文件）。点通道的监测快照（十分钟离群率）也要随之重算，因为数据层的爆发用它；每小时的小时均值不随零级变化（变换域）。

**变体（三档，均在选项一下）。** 甲：重估窗口一天（第一批默认）；乙：七天；丙：只重估位置（中位数七天，分母冻结）。三档的其余参数相同。另跑一个开环对照（命令不执行），它应与聚合模块收口时的默认配置逐条相同——这是驱动程序本身的正确性检验。

**运行前写定的闭环预期**（片段矩阵，均为测量项，结果是什么记什么）：

| 片段 | 闭环预期 |
|---|---|
| 气体自三月十四日起的抬高 | 三月十五或十六日日界对 B、D、E、H 等发零级；生效后数据层气体回到正常；乙与丙档不出现湿度气压的连带偏离，甲档出现（数据事实第三十九条候选）。 |
| 三月二十二日至二十七日事件 | 在新参照上成为新的一段偏离，八台各发一条零级（E 在内）；生效后数据层回到正常。 |
| 四月五个共模气体时段 | 落在正常状态上，多数小时归为"环境事件"而非"漂移"；跨日界的时段产生零级后，回落时数据层看到向下偏离并以第二次零级映回（丙型实例，计数）。 |
| C 的正午日照直射 | C 不再长期处于温度漂移期，正午小时按累计计数从第三次起归为"现场条件"（若上下文标志仍不足三窗口，则记为无标志，不改门槛）。 |
| G 的光照 | 三月十二日前后一条零级，生效后光照回到正常并保持到四月下旬。 |
| 十四段注入异常 | 所在小时多数归为"异常"（E 不再长期处于漂移期）。 |
| 平稳日 | 零级之后命令显著少于开环的四条；仍出现的命令逐条列出触发通道。 |
| 全程 | 零级命令总数、每台命令数、命令之间的最短间隔；丙型（命令后回落再命令）实例数；三档并排。 |

**判读口径。**
1. 开环对照与聚合模块收口基线逐条相同（驱动正确性）。
2. 三档的命令清单与片段矩阵并排。
3. 每条命令生效后七天内，触发通道与非触发通道的数据层偏离日数（第三十九条候选的闭环检验）。
4. 每条命令生效后点通道离群率的变化与状态重建瞬态。
5. 丙型实例逐条：命令、回落日期、第二次命令。
6. 重估窗口的选定判据（运行前写定）：以"命令总数最少且非触发通道连带偏离日数最少"为优先，两者冲突时以连带偏离日数为准；若丙与乙在两项上都相当，取乙（全重估更简单）。选定值由设计会话按此判据宣布，之后作为一级与二级开发和全量重放的默认值。

**验收（V-M6b-2）。** 判读口径六条填写；驱动程序的开环对照逐条相同；Java 模拟器与 Python 参考在每条命令的新参数上逐位（光照 1e-12）相同。

## 第五节：第三项——一级与二级（决定十六、十七）

**上下文模块的改动。** 其一，选项一：保存训练版本参数集，自己标准化，输出训练版本号；参数集从数据接入模块每个版本第一条轮的附件读取并缓存全部版本。其二，一级：收到一级命令后，在生效时刻启动热启动重训（异步训练机制），训练集为最近 N 天入口轮按当前版本标准化、剔除含离群轮的窗口；新模型标定完成后在下一个窗口边界原子切换；切换前旧模型按旧训练版本继续评分；切换后输出版本号为新训练版本，性能层清空该台历史（新模型的误差分布与旧的不可比）。其三，二级：回到收集态，按首次训练的数据段重训；期间该台上下文输出与性能层静默并在质量信号里标明"重训中"。其四，影子评分开关（只在全量重放打开）。

**适应执行模块的改动。** 命令级别一与二的执行入口：数据接入模块对一级与二级不重估参数（除非同一命令同时带零级），只把命令转发到上下文模块（经标注轮的附件，与零级同一机制）；版本号不变。

**聚合模块的改动。** 决策矩阵的升级格按决定十六：只有性能层持续，一级；一级后 K_up 天内性能层再次确认，二级；两层同报，一级；只有数据层持续，零级，零级后 K_up 天内同一通道再次持续，一级。命令携带级别；冷却期按级别分别计（一级与二级的冷却期默认为该台重训完成后七天，参数）。

**开放问题第十二条的离线实验（在线实现之前做）。** 用 `M6aContextEval` 的训练工具：以三月事件为用例（模型在事件前训练，事件后三月二十八日起重训），N 取三、七、十四天，热启动与冷启动各一组，五个种子；量三项：重训耗时与轮数；重训后七天平稳段的超阈率；重训后对注入段（四月五日尖峰与阶跃）的召回。运行前写定的判据：热启动与冷启动在后两项上无系统差别则取热启动（便宜）；N 在后两项不再改善处取最小值。选定值写入一级的默认参数。

**验收（V-M6b-3）。** 单元测试（训练版本标准化、参数集缓存、一级切换原子性、二级静默、影子评分）；开放问题第十二条实验报告；短重放（三月二十四日至三十一日，对 G 手工下发一条一级命令）两次运行逐位相同、切换前后版本号与评分的连续性核对、旧模型服务至切换的证据；命令回路关闭且未重训时全部输出与第一批收口逐位相同。

## 第七节：第五项——全量重放（决定十八）

**设置。** 三月一日至四月三十日，一百五十倍速，有限重启三次，检查点三十秒，全部模块、命令回路与聚合模块打开，上下文模块影子评分打开，注入段保留。

**断言。** 重放完整性八条全部成立（含迟到命令为零）。

**等值。** 其一，第一条一级或二级命令生效之前，点通道判定、数据层日记录、聚合模块三份日志与链式离线实验（选定的重估窗口档）逐条相同——在选项一下上下文通道的输入不随零级变化，而补遗四已证明上下文训练在相同输入下逐位可复现，所以这一段在线与离线应当一致；上下文主分与此前全量运行逐位相同。其二，第一条一级或二级之后，离线无法复现训练，改为两次全量重放逐位相同（补遗四的判据）。

**影子评分的判据（用户要求的再验证）。** 每台在每次零级生效后七天内，影子超阈率（按当前版本标准化）与正式超阈率（按训练版本）并排；预期影子超阈率在零级后明显高于正式超阈率（与离线的两成五至八成一致），且性能层在正式评分上不因零级产生确认。若影子超阈率不高于正式超阈率，说明在线数据上零级恰好抵消了漂移，选项一的收益不成立，记录并带回理论线。

**验收（V-M6b-4）。** 断言八条；等值两段；影子评分表；时延表（三月事件、G 光照、气体抬高从第一条信号到零级生效、到一级切换）；性能表（检查点体积、重训耗时、排空时长）。
