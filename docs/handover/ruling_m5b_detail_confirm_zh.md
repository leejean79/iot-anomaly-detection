# 裁决：M5b 实现说明第三节八条细节的确认（开发设计日志 0.94 版，用户 2026-10-20 转达）

八条逐一确认如下，七条照它的选定，一条要改（第六条）。

第一条，方差用样本方差、分母取 n 减一，确认。论文写的 σ 没有说明分母，样本方差与教科书的韦尔奇 t 检验和 F 检验一致，也与我们"按论文实现、论文未定处按教科书"的原则一致。

第二条，窗长上限取两千零一十六，确认。以正文"超过上限时移除最旧元素"为准，算法伪代码第五行的不等号按笔误处理，登记在报告的文献勘误一节里。

第三条，无解时切点取向下取整的一半，确认。这是算法 2 第八行的写法，作者代码多加一的做法不采用，与"按论文实现"一致。

第四条，临界值表的自由度取法确认：F 临界值的两个自由度是切点减一与窗长减切点减一，t 临界值按式 4.12 在实际切点比例处取自由度。

第五条，事件里的漂移幅度定义为新子窗均值减历史子窗均值、再除以历史标准差加防除零常数，确认。

第六条，持续性核对的滑动中位数要改：只用候选之后的元素，满六个之后才开始比较，K 从候选之后的第一个元素起计数。理由是候选之前的元素属于漂移前的水平，把它们混进滑动中位数会把中位数往参照值方向拉，前五次比较就容易把真正的持续抬高误判成"回落"而撤销候选。交接文档里"凑满六个元素之后才开始比较"指的就是候选之后的六个。

第七条，核对门限为参照值加鲁棒度乘历史子窗的样本标准差，鲁棒度与检测器共用同一个参数，确认。不另设参数。

第八条，两个子窗都为常数时不做 t 检验、视为不显著，确认，并请计数进监测快照，与"方差显著但均值未升"的计数并列。
