# 裁决书：性能层离线网格的结果与四项待裁事项
# （开发设计日志 0.98 版）

> 发出方：开发设计会话。接收方：代码开发 agent；第三节带回理论线。
> 依据：《M5b 离线网格运行结果与需要设计会话知道的事实》（2026 年 10 月 21 日）；口径文件 `m5b_offline_protocol.md`（运行前确认）。

## 第一节：对结果的认定

这是本项目第一次在真实数据上检验漂移监测的理论主张，结果比预期清楚。按运行前写定的七条口径，默认组合的表现是：五十个平稳设备日上只有一条确认，十一条候选里十条被持续性核对撤销；三月事件尾段八台中七台确认（第八台的评分在尾段才开始），其中六台由方差检验触发；尺度漂移日十七个设备日中七个有确认，全部由方差检验触发；C 的日照直射五段中四段有候选、零确认，傍晚气体上升八台中七台有候选、零确认；十四段注入异常七段有候选、零确认，包括与 K 恰好相等的六小时爬坡这一边界情形。三十六种组合的 Java 与 Python 事件清单逐条相同。

这些数字对理论的意义，逐条写进第三节。验收项二（离线实验）通过。

## 第二节：四项裁决

**第一项，保持默认组合，确认。** 规则的第一条（默认在平稳日上明显更高）对任何邻近组合都不成立，不更换。附带记录三条邻近组合的事实，它们没有参与选择，但说明默认取值处在合理的位置：小时粒度在三月尾段零确认，原因是三十个元素的初始化要三十个小时，加上窗上限只有三百三十六，它不适合本数据的时间尺度；K 等于十八在平稳日上四条确认，K 等于七十二在三月尾段只有一台确认，默认的三十六在两者之间。

**第二项，"方差显著但均值未升"的计数不触发"允许方差检验独立报警"，理由如下，并以此关闭理论回传第十八条里的这个问题。** 三月尾段上这类情形出现一百九十七次，确实明显非零；但同一段里七台设备中六台已经由"方差显著且均值升高"的单侧 F 检验确认，单侧实现没有在这里漏掉漂移。反过来看平稳日：五十个设备日上这类情形出现七十七次，若允许方差检验独立报警，平稳日上的候选会从十一条变成几十条，而持续性核对的判定依据是水平的持续抬高，这些候选最终仍会被撤销——结果是候选暴涨、确认不变。更根本的是语义：性能层监测的是"模型是否变差"，重构误差的离散程度扩大而水平不变，意味着误差的分布变宽但模型平均而言没有变差，它会抬高超阈率，但这属于告警率流的监测范围（理论第十一条决策预留的"离群率序列"一路，由聚合阶段接同一份检测器实现），不属于性能层的水平监测。所以保持单侧，理论第五条决策第二条理由的表述修正为"离散程度扩大并伴随水平抬高的变化能被抓住"，纯离散变化的监测归告警率流。

**第三项，不给持续性核对加最小绝对幅度，但把幅度交给适应执行模块的触发门控。** 平稳日上没有极小幅度的确认，这一条担心在真实数据上没有出现，不加新参数。平稳日以外有五条绝对幅度小于零点二五个主分的确认，五十一条确认里有二十八条确认时的水平低于告警阈值二点二二、六条低于零——它们在统计意义上都是水平的持续抬高，但抬高的量对检测没有后果。处置是：性能层如实发出全部确认事件并携带幅度；要不要对小幅度的确认做响应，是适应执行模块的问题（理论第四条决策的触发门控本来就在那里）。登记为开放问题第十三条：零级响应的触发是否设最小幅度（以主分为单位），取值依据就是这次得到的确认幅度分布。

**第四项，七个跨设备同时确认的时段要核查成因，作为纯分析任务，不阻塞收口。** 前两个时段在三月事件尾段之内，成因已知。其余五个（四月三日凌晨、四月四日上午、四月九日夜间到十日凌晨、四月十五日傍晚、四月二十二日凌晨）是至少三台设备在六小时内同时确认，这正是聚合模块要区分的共模条件。按"数据出处优先"约定的顺序：出处材料里没有这类事件的记录（已核实自述文件只有部署描述），所以直接查数据本身——对每个时段给出机队五个通道按当地时间的逐小时剖面与跨设备对照，看是气体、温湿度还是光照在动、是否全机队同步、持续多久、是否回落。产出 `docs/reports/fleet_drift_episodes.md`，只报事实。查明的归因进论文证据案例清单，它们是聚合模块共模判别的现成用例。

## 第三节：带回理论线的事项

第十九条（新增）：性能层在真实数据上的首次定量结果。持续性核对（理论第四条决策的信号侧防线）把平稳日候选的十一分之十挡住，十四段注入异常零确认，C 的现场条件零确认——信号侧防线的设计在真实数据上成立。三月事件尾段七台中六台由方差检验先触发、尺度漂移日的确认全部由方差检验触发——理论第五条决策第二条理由在"伴随水平抬高"的意义上得到印证，表述按本裁决第二项修正。小时粒度不适合本数据的时间尺度，十分钟粒度加六小时持续性是合理取值。

第十八条（关闭其中的开放问题）：不允许方差检验独立报警，纯离散变化归告警率流监测。

第四条风险（盲区）：实测盲区内错过两段，都是 D 的尺度漂移日（三月二十七日与四月十日），登记。
