## 第一节：零级重估窗口锚定在变化点之后

**定义。** 零级命令携带触发通道及各自的进入偏离之日（聚合模块已知，来自数据层的状态转移）。标准化算子执行零级时，重估窗口的起点取"全部触发通道中最早的进入之日的当地零点"与"生效时刻减七天"两者中较晚者，终点仍为生效时刻；也就是说窗口不早于变化点、不长于七天。窗口长度不足 L_min（默认两天，参数）时回退到"生效前七天"并在执行日志里标明"回退"。重新冻结的参照直方图与重估用同一窗口。湿度与气压仍不重估（开发决策第十二条）。

**两种作用范围，作为两档。** 乙档：锚定只作用于触发通道，非触发通道（例如气体触发时的温度与光照）仍用生效前七天；丙档：锚定作用于全部被重估的通道。甲档为现行默认（生效前七天）作对照。预期在运行前写定：乙与丙都减少三月事件中的第二条命令（A、B、G 的同向第二条）与事件后平稳日的伪命令（三月三十日、四月十七日那几条），七天内的丙型实例由十一例下降；丙档非触发通道的连带偏离日数可能高于乙档（短窗口对非触发通道不具代表性，数据事实第三十九条的机理）；两档命令总数都不多于六十。选定判据沿用第二批：命令总数最少且非触发通道连带偏离日数最少为优先，冲突时以后者为准，相当时取更简单的乙。

**实现。** 命令契约加字段"触发通道的进入之日"（数组）；标准化算子的零级纯函数加窗口起点参数；链式驱动与 Python 参考实现同步；聚合模块的命令生成填入进入之日。在线作业参数 `--adapt-anchor`（取值 off、trigger、all，默认 off）。

**验收（V-M6c-1）。** 单元测试（起点取较晚者、回退、多触发取最早、两档作用范围）；链式三档并排与选定；Java 与 Python 在每条命令的新参数上逐位（光照 1e-12）。

## 第二节：一级切换前验证的默认值

**材料。** 第二批两次全量重放的十三次一级切换（含三次"会拒绝"：H 9.75、B 5.94、D 3.57）与第一次全量重放的十次（含两次：B 4.08、H 7.22）。

**离线复算。** 对每次切换，用离线训练工具按在线同一口径（训练集、版本、种子）复训，得到新模型；评分两组：切换后七天的入口轮分别用新模型与旧模型（上一代）评分，给出超阈率、主分中位数、第九十五百分位；并列出切换后七天内该台是否触发了新的一级或二级。同主机上与在线训练的比值应相同（逐位等值方法手册第五条的边界内）。

**运行前写定的判据。** 若在"会拒绝"的五例中至少四例，新模型切换后七天的超阈率高于旧模型评分的两倍以上，且其中至少三例在七天内触发了新的一级或二级，则验证默认开启，倍数取使这五例被拒而其余十八例全部通过的最小整数（预期为三）；若不满足，验证保持关闭，比值只记录。开启时的行为按 1.43 版裁决：不切换、旧模型继续服务、标记"一级不切换"，并视为一级失败一次（两次失败后放弃该次一级，按第二批写法）。

**验收（V-M6c-2）。** 复算表二十三行；判据的结论；若开启，单元测试与短重放中构造一次"会拒绝"的切换证明旧模型继续服务且输出逐位可复现。

## 第三节：连续反向命令作为升级信号；跨级冷却

**振荡规则。** 同一台同一触发通道在十四天内（参数）出现两条偏移符号相反的零级命令（即一个丙型实例）后，该通道再次命中零级格时不发零级，改为"只记录"并在复核日志写"零级被抑制：基线振荡"，告警标签加"基线振荡"；抑制持续到该通道回落一次或十四天过去。理由：来回重估说明参照在新旧工况之间摆动，再重估只是再摆一次，正确的做法是停下来等它稳定或交给人工。这是理论矩阵"隔离该设备加人工审计、不重训"一行在零级上的对应物，登记为理论回传第三十一条。

**预期。** 在链式实验（第一节选定的档）上，振荡规则使丙型实例的第三条及以后的命令消失，命令总数再降；不改变三月事件与 G 光照的首条命令。

**跨级冷却。** 本阶段只做事后统计，不实现：从第二批全量重放中数出每台在一级切换完成后三天内收到的零级命令、以及零级生效后三天内提交的一级重训，列表并注明各自的触发；若两类交叉触发合计少于五次，跨级冷却不做，写入收口记录；否则第四批再议。

**验收（V-M6c-3）。** 单元测试；链式实验加振荡规则一档的并排；交叉触发统计表。

## 第四节：二级重训期间的监测预案；二级触发条件复核

**预案。** 二级收集期内（默认十六天），该台上下文通道与性能层静默，数据层与点通道照常，聚合模块对该台的归因只用这两层（已是现状）；补三件事：其一，告警里给该台加"上下文重建中"标记及剩余天数；其二，每个日界为该台出一条"重建期日报"写入复核日志（当日数据层各通道状态、点通道离群率、距上线天数）；其三，重建完成上线时发一条告警"上下文通道恢复"，并把新模型第一周的超阈率与上一代最后一周并排写入复核日志。不改变二级的时长与训练段。

**触发条件复核。** 第二批的两次二级（D 三月三十日日界、A 四月十三日日界，第一次全量重放还有 B 四月二十三日日界）都命中"一级之后七天内性能层新确认段"。对每一例回答：那条一级的切换比值是多少（是否在"会拒绝"之列）；切换后性能层确认段开始时，数据层同通道是否也在偏离（真漂移）还是只有性能层（模型本身不好）；若把第二节的验证开启，这条一级会不会被拒、二级会不会因此不发生。用第二节的复算结果直接回答。

**运行前写定的候选规则（由复核结果择一，带回理论线）。** 甲：现状，一级后七天内性能层新确认段即二级；乙：二级只在"一级切换验证失败两次"或"一级切换后七天内性能层新确认段且数据层同通道同期偏离"时发生——前者是模型学不好，后者是漂移继续；只有性能层、数据层不偏离时，先再做一次一级。乙的实现在本阶段做成参数、默认关闭。

**验收（V-M6c-4）。** 预案三件事的单元测试与短重放；三例复核表；候选规则的裁决依据。

## 第六节：顺序与一次全量重放

1. 第二节的离线复算与第四节的复核（只用已有材料与离线训练工具）。
2. 第一节的链式三档与第三节的振荡规则一档（开发机，每档约半分钟）。
3. 在线实现（锚定、验证、振荡、预案、候选规则乙），全部参数化默认关闭；短重放证明关闭时与第二批收口逐位相同、开启时两次运行逐位相同。
4. 一次全量重放（两次运行），按第一、二、三节的裁决开启选定的项，核对口径沿用第二批（八条断言、等值两段、九类输出、数据发完无保持）。
5. 文档与材料清单；第三批收口记录，各项默认值的最终裁决。
