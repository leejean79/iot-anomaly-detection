# 裁决书：数据层离线实验的结果——两处预期落空的归因、两项设计更正、四项裁决
# （开发设计日志 1.09 版）

> 发出方：开发设计会话。接收方：代码开发 agent；第四节带回理论线。
> 依据：《M5a 离线实验结果》与《需要设计会话知道的事实》（2026 年 10 月 25 日）。图解见 `figs/m5a_two_findings.png`。
> 总评：实验按运行前写定的口径完成，九条口径全部有数；与预期不符的两处——离群率一族零确认、平稳日上长记忆几乎天天报——按"不迎合"约定的顺序逐一归因：前者是交接文档的设计错误，可以从结构上证明；后者不是误报，是长记忆在没有适应机制的系统里的正确行为，错的是交接文档的预期。两处都不改门槛、不改参照、不改判读清单。

## 第一节：离群率一族零确认——交接文档的设计错误，更正第三族的事件语义

**事实。** 十分钟离群率百分之九十八点四为零，每台最长的连续非零只有一到九个元素；二百四十五条候选全部在刚凑满六个元素时撤销，撤销时最近六个的中位数为零。三月事件的起点上，A 与 C 在二十二日零时二十分就有候选，其余各台在当天到次日也有，但没有一条被确认。

**归因。** 这不是数据的问题，也不是理论的问题，而是我把性能层的持续性核对原样套到了一个性质完全不同的信号上。点异常检测模块的滑动窗是一小时：分布切换时新分布的早期样本找不到邻居而被批量判为离群，一小时后窗口周转完成、新分布有了邻居，离群就停止。所以点通道的"爆发"长度被窗长封顶在一小时以内——这正是理论第十二章形态学规律的另一半，当时没有写出来。而持续性核对要求六小时内过半的十分钟有离群，对一个被封顶在一小时的信号，这个条件按构造永远不成立。这一点不需要实验也能推出来，交接文档没有推，是设计错误。

**更正。** 第三族的事件语义改为"爆发"：最优窗口检测器对离群率序列的候选本身就是事件（它是一次统计显著的离群率上升），不再经过持续性核对；事件携带爆发的大小（候选起一小时内的离群轮数与离群率峰值）与持续长度。理由：持续性核对的作用是在水平型信号上区分异常与漂移；爆发信号是变化点的标记，它本身不回答"是异常还是漂移"，这个问题由同一时刻之后长记忆与逐日统计量怎么走来回答（两层同报表与决策矩阵的事）。更正不引入任何新门槛：候选就是检测器自己的检验。

更正之后重新出具第二、四、五、六条口径中离群率一列（候选即事件），并补一张"爆发与次日长记忆事件的对照表"：每一次爆发之后的当地日该台是否有长记忆事件或越门槛，这是理论"离群点爆发是分布切换起点"在真实数据上的检验。

## 第二节：平稳日上长记忆几乎天天报——不是误报，是没有适应机制时长记忆的正确行为；更正事件语义为状态转移

**事实。** 四十六个可判的平稳设备日里四十五个有长记忆事件；温度事件二百条中一百八十条偏移为正，气体事件二百三十三条全部为正。两种参照的对照表给出了原因：训练期参照（三月八日至十七日）相对标定周（三月一日至八日），气体中位数高出三成到八成，温度高零到零点五摄氏度，气压低近一千帕。附表显示气体通道从三月十四日起每天有六到八台报警。

**归因。** "平稳日"是相对训练期参照、以零点五个宽度为容差定义的；长记忆的参照是标定周。两份参照不在同一个水平上：三月中旬起这间办公室的气体水平抬高了，之后再没有回到标定周的水平（见图上半幅）。所以平稳日相对标定周已经不平稳，长记忆照报，而且报得对——它报告的是"环境相对标定期发生了持续的变化，而系统没有适应"。三月二十二日的事件之前一周已经有这个抬高，是本次实验新查明的事实。交接文档"平稳日上长记忆事件理论预期为零"这句话错在用了另一份参照定义的"平稳"去预期一个以标定周为参照的检验。

**这意味着什么。** 长记忆看到了两个检测通道看不到的东西：点通道的半径和上下文通道的模型都是在三月中旬以后的数据上标定与训练的，它们把抬高后的水平当作正常；只有以标定周为参照的长记忆知道水平变过。这正是理论给数据层长记忆的任务。它同时也说明：长记忆的报警在没有适应机制的系统里必然是持续的——一旦漂移发生且无人适应，此后每一天都会报。所以衡量长记忆的量不是"平稳日上的事件数"，而是"进入漂移状态的日期、持续时间、回落日期"。

**更正。** 长记忆事件的语义改为状态转移：每台每通道维持一个状态（在参照范围内、已偏离），某日 D 超过 D 零时若原状态为"在范围内"则发出"进入偏离"事件，某日 D 回到 D 零以下时若原状态为"已偏离"则发出"回落"事件；日记录继续逐日给出 D、偏移与宽度倍数。门槛、参照与判读清单都不改。重新出具第一条口径时，平稳日一栏改为给出每台每通道的状态转移日期清单，并保留原按日计的事件数作对照。

## 第三节：其余三项裁决

**三种统计方案的差别几乎看不出来（第五项验证）。** 原因与第二节相同：相对标定周的真实偏离在几乎所有日子上都远超任何门槛，校正与效应量门槛没有用武之地。这一结论如实登记：第五项验证在本数据的三月九日至四月三十日段上不能分辨三种方案，因为这一段没有"相对参照平稳"的日子；分辨它们需要一段相对参照真正平稳的数据，这只有在适应执行模块重新冻结参照之后才会有。第五项验证推迟到那时在同一张片段矩阵上重做，本阶段的三方案表保留为"真实漂移下三者同报"的记录。

**已登记尺度漂移日清单里光照条目的域不同。** 已登记清单在原始光照值上算宽度倍数，本阶段在对数变换域上算。清单冻结不改；第三条口径中光照的十四个设备日标注为"域不可比"，不参与"越尺度门槛与长记忆是否一致"的汇总。登记一条数据事实候选：光照的日内宽度倍数在原始域与对数域上相差一个数量级（原始域三到十五倍，对数域一点一到一点五倍），以后凡引用光照的宽度倍数都必须注明域。

**分箱 D 的误差。** 实验日上最大零点零五二七，都在可证明的界之内，成因是夜间光照并列值占当日四分之一的质量。接受，报告中注明即可。

## 第四节：带回理论线

第二十二条：点通道的离群点爆发被滑动窗长封顶（本系统为一小时），它是分布切换的变化点标记而不是持续信号；对它做持续性核对在构造上不成立。理论第十二章的形态学规律应补上这一半，决策矩阵里"离群爆发"一格的语义是"变化点"，异常与漂移的区分由其后长记忆与逐日统计量的走向决定。

第二十三条：长记忆检验的报警是有状态的——漂移发生且未适应时，此后每天都报；它的度量应是进入偏离的日期、持续时间与回落日期，而不是逐日的报警计数；"平稳日"的定义必须与检验所用的参照一致，否则预期无意义。本数据上长记忆查明：气体水平自三月十四日起相对标定周持续抬高三成到八成（三月二十二日事件之前一周已开始），温度略升，之后未回落；两个检测通道因标定与训练在抬高之后而看不见它。这是适应执行模块"重新冻结参照"的最直接依据，也是论文里"长记忆看到检测器看不到的东西"的实例。

第五项验证推迟并改写前提：三种统计方案的对决需要一段相对参照平稳的数据。

## 第五节：验收与后续

验收项二按"测得、稳定、可归因"的标准**通过**：九条口径全部有数，两处预期落空都已归因并有结构性解释，不改门槛与参照。代码开发 agent 按第一、二节的两项语义更正修改离线工具与在线实现，重新出具受影响的表（成本是重跑离线脚本，不涉及重放），然后做验收项三的短重放等值与验收项四、五。两项更正属于事件语义，不是参数，不需要再做运行前口径的确认，但更正后的事件定义要写进离线操作口径的修订版。
