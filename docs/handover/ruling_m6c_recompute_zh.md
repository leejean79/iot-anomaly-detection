# Ruling: Three Items from the Level-1 Switch Recomputation and Level-2 Review

> 接收方：代码开发 agent。

## 第一项：判据不满足，验证保持关闭——确认，并登记一条比判据本身更重要的事实

按运行前写定的判据，五例"会拒绝"中只有一例切换后七天新模型超阈率高于旧模型两倍（H 第一次全量重放命令六），零例随后触发新的一级或二级，验证保持关闭、比值只记录，在线实现仍加"一级不切换"标记与失败计数、默认关闭。

但这张表说明的不只是"判据不满足"。切换比值（新旧模型各自标定段误差中位数之比）与切换后的实际表现几乎无关：比值 9.75 的 H 与 3.57 的 D，切换后超阈率都是零；比值 1.43 的 A（第二批重跑命令三）切换后超阈率 0.58 对旧模型 0.018，比值 0.96 的 D（第一次命令六）为 0.347 对 0.002，比值 1.73 的 C 为 0.45 对 0.03——真正坏的切换都通过了验证，被"拒绝"的反而多半没事。原因在统计量本身：新模型的标定段只有三天且紧接变化点，它的误差中位数反映的是那三天数据的噪声水平，不是模型的好坏。**登记为数据事实第四十五条候选，并作为理论回传第三十二条**：理论矩阵"一级，重训后验证"中的验证不能用新旧标定段误差之比；切换前能做的检验（两个模型在同一段近期数据上各按自己的坐标评分）也不构成有效性判据，因为新模型在那一段上按构造是校准过的。可行的方向是事后判据——切换后一周新模型超阈率相对旧模型最后一周明显升高且数据层同通道未偏离时回退到上一代——这是第四批的候选，不在本批做。

## 第二项：C 的跨主机差异百分之四点八——登记为方法事实，修订手册第五条

诊断停在代码层且不是缺陷：输入相同（首轮损失相对差千万分之七），差异在冷启动训练过程中逐轮放大到百分之十，新模型训练四十一轮两边一致到千万分之二。跨主机训练的数值发散没有简单的轮数规律（E、B 更长却一致）。手册第五条的"连续量相对差约百分之一以内"改为"通常在百分之一以内，个别训练实例可达百分之五；跨主机不作等值断言，只报告并排数值与离散决策量是否相同"。

## 第三项：候选规则乙的口径与取舍——口径确认，取甲，不做 D 的重跑

代码开发 agent 对乙的理解正确（"同一通道"取该次一级的触发通道，"数据层偏离"取确认段开始当日或前两日的日记录）。三例复核的共同事实是：性能层确认段开始时，触发通道的温度在数据层仍在偏离，也就是重训之后漂移仍在继续，二级是对"再训一次也追不上"的合理回应；A 与 B 切换后新模型的超阈率确实明显高于旧模型（0.56 对 0.24，0.77 对 0.07）。乙在三例上与甲结果相同，没有证据支持改规则，取甲；乙不实现为参数，省去一处无用的分支，交接文档第四节相应更正。D 的"若验证开启二级是否仍会发生"不做：验证已定为关闭，这个问题不再有决策价值。
