# 交接文档：数据层漂移监测模块（M5a）阶段
# Handover: M5a Data-Layer Drift Monitoring Stage

> **发出方**：开发设计会话（开发设计日志 1.02 版；八项设计决定经用户 2026 年 10 月 22 日确认，本文档为正式交付版）
> **接收方**：代码开发 agent
> **前置声明**：本阶段的代码开发遵守项目 `CLAUDE.md` 的全部适用条款。本模块不修改数据接入、点异常检测、上下文异常检测与性能层漂移监测四个已收口模块的任何语义；它消费数据接入模块输出的标准化轮、点异常检测模块的离群标志与监测快照，复用性能层的检测器实现。
> **术语说明**：冻结参照指数据接入模块在标定窗口（七天）结束时冻结的每台设备每通道的分布，本阶段用它的样本（标定窗口内的标准化读数）作为长记忆的参照；柯尔莫哥罗夫–斯米尔诺夫检验（下文简称分布检验）比较两组样本的经验累积分布，其统计量 D 是两条累积分布曲线的最大竖直距离；邦费罗尼校正指把显著性门槛除以同时进行的检验次数；效应量指统计量本身的大小，与显著性相对；离群率指点异常检测模块在一段时间里标为离群的轮数占总轮数的比例。

## 第零节：八项设计决定（已确认）

**决定一：数据层由三族信号组成，分别对应三种变化的时间尺度。** 理论文档对数据层的要求是"对原始特征逐个做分布差异检验并做邦费罗尼校正"，又在第十五条回传里把缓慢漂移划归"数据层的长记忆监测"，在第十一条决策里把点异常检测模块免费提供的三路健康信号也接到数据层。把这三条要求合起来，数据层有三族信号。第一族是长记忆的分布检验：每台设备每个通道，按当地时间把每一天的标准化读数与冻结参照做分布检验，抓的是相对标定期的累积偏离，缓慢的季节趋势只有它看得见。第二族是逐日的位置与尺度统计量：每台每通道每天的中位数偏移（以参照宽度为单位）与宽度倍数（当日第十到第九十百分位距离除以参照的同一距离），这正是开发线此前离线算的日剖面在线化，也是开放问题第八条要的零级响应触发统计量。第三族是点通道的免费信号：每十分钟的离群率，接性能层已经做好的最优窗口检测器与持续性核对，抓的是突变——理论第十二章的形态学规律说分布切换的起点表现为离群点爆发，这一族就是它的监测器。三族信号的示意见第二节的图。

**决定二：参照取冻结的标定窗口，比较的粒度取当地时间的一天。** 长记忆的本质是参照不随时间滑动。以标定窗口（三月一日至八日）内的标准化读数为参照样本，每一天的读数与它比较。按天比较有两个理由：一是昼夜周期是本数据最强的结构，比一天短的窗口与参照比较时，比出来的首先是时刻差异而不是分布变化；二是逐日的口径与已经登记的平稳日、尺度漂移日、日剖面完全一致，判读不需要再换口径。按当地时间划分日界，因为英国夏令时在二〇二二年三月二十七日开始，按世界协调时划分会让昼夜形态在那一天之后整体错一小时。突变的检测不靠这一族，由第三族承担，所以按天的时延不是问题。

**决定三：显著性与效应量两道门，门槛都从参照自身推导。** 一天有八千六百四十轮，分布检验的样本量很大，任何微小差异都会显著，只看显著性等于天天报警。所以每个通道的检验要同时过两道门：第一道是显著性，显著性水平零点零一，除以同时检验的通道数五做邦费罗尼校正；第二道是效应量，统计量 D 必须超过门槛 D 零，D 零的取法与平稳日尺度门槛 W 相同——把标定窗口七天中的每一天分别与整个标定窗口做分布检验，取七个 D 的最大值，再在设备与通道上取最大值，向上取整到两位小数。标定窗口内出现过的日间差异是"学过的正常"，超过它才算分布变化。D 零不得由实验结果反推。

**决定四：第三族信号的参数照抄性能层，不另调。** 离群率每十分钟一个元素（该十分钟内离群轮数除以轮数），送入与性能层同一份最优窗口检测器实现与同一个持续性核对，参数取性能层收口时的默认组合（置信度零点九九、鲁棒度零点五、K 等于三十六）。这正是理论第十一条决策"一份实现到处复用"的落地，也让两层的事件可以直接并排。邻居数分位数与微簇占比两路信号，请代码开发 agent 先核对点异常检测模块的监测快照里现在能拿到什么（已知有微簇计数器），能拿到的照同样方式接入，拿不到的登记为后期事项，不为它们改点异常检测模块。

**决定五：质量门控。** 一天里缺轮比例超过门槛（建议百分之二十，参数）或守卫打标的轮数超过门槛的设备日，标为"不可判"，不做分布检验，不产生事件，但产生一条带原因的记录。理由是理论第四条决策的双防线要求漂移信号本身要门控，而缺失与卡死会制造假的分布变化。门槛值写入配置，运行前定，不以结果调。

**决定六：输出与接口。** 数据层事件写入性能层已经建立的漂移主题，字段加一个"层"标记（数据层或性能层）与通道名；长记忆事件携带 D、校正后的显著性、偏移与宽度倍数；离群率事件与性能层事件同构。逐台逐通道逐日的位置与尺度统计量作为一条日记录写入监测主题，这是适应执行模块零级响应的输入。本阶段只发出，不消费。

**决定七：离线实验先行，不重放；判读口径运行前写定，并把理论第五项验证一并做掉。** 长记忆与逐日统计量可以直接从原始数据与冻结参照离线算出；离群率可以从注入运行的点通道离群记录转储算出。实验覆盖三月八日（冻结）至四月三十日，比性能层多出十六天，三月事件的起点（二十二日）在覆盖范围内。判读口径沿用性能层的片段矩阵并新增三条，见第四节。理论第五项验证要求数据层的统计方案三者对决——原文方案（对各特征取最大统计量、不校正）、分布检验加邦费罗尼校正、卡方校准的似然比检验——在同一份数据与同一张片段矩阵上做，报告三者在平稳日上的误报与在片段上的命中。

**决定八：两层同报表与边界。** 性能层已有的事件清单与本阶段的事件按片段并排，产出第一张"两层同报表"，逐片段写明哪些层在哪个时刻报了，这是决策矩阵的经验基础，也是理论第四项验证的素材。本阶段不实现路由，不实现共模判别（聚合模块），不实现任何响应（适应执行模块）。在线验收只做短重放上的离线与在线等值。

## 第一节：任务的一句话说明

在每台设备上建立三族数据层信号——按当地时间逐日对冻结参照的分布检验（带邦费罗尼校正与效应量门槛）、逐日位置与尺度统计量、点通道离群率接最优窗口检测器——以事件流与日记录发出；先在三月八日至四月三十日的数据上做离线实验与三种统计方案的对决，再在短重放上证明在线实现与离线工具逐位相同。

## 第三节：代码改动

**参照样本的保存。** 数据接入模块在冻结时只保存了中位数与四分位距，长记忆需要标定窗口的样本本身。实现为：数据接入模块冻结时把标定窗口内每通道的标准化读数按固定分辨率压成直方图（建议每通道四百个等宽箱，范围按标准化读数的实测范围加余量），存入受检查点保护的状态并随快照导出；分布检验用直方图的累积分布近似，报告中注明近似精度（箱宽即 D 的分辨率）。这是对数据接入模块唯一的改动，只增不改。

**数据层算子 `M5aFunction`。** 按键处理函数，接在数据接入模块之后与点异常检测模块并行；按事件时间的当地日界聚合每通道的直方图与计数，日界到来时做五个通道的分布检验与位置尺度统计，发事件与日记录；质量门控按缺轮与守卫打标计数；状态受检查点保护。

**离群率流。** 从点异常检测模块的输出按每十分钟聚合离群率，送入 `OptWinDetector` 与 `DriftGate` 的新实例（每台设备一个），事件层标记为数据层、通道标记为"离群率"。

**参数。** 显著性水平、效应量门槛 D 零、直方图箱数、缺轮门槛、守卫打标门槛、数据层总开关。

**离线工具。** Python 参考实现读原始数据与冻结参照，算三族信号与三种统计方案；Java 离线运行器读同一份数据，用于等值；判读脚本生成片段表、两层同报表、方案对决表。

**测试。** 直方图累积分布与精确经验累积分布的 D 误差不超过一个箱宽；分布检验的 D 与显著性与 scipy 一致；邦费罗尼校正；日界按当地时间（含夏令时切换日）；质量门控；检查点恢复后直方图与日累计存活；Java 与 Python 事件逐条相同。

## 第四节：离线实验与判读口径

**数据。** 三月八日至四月三十日，八台设备，原始数据按数据接入模块的冻结参数标准化（离线工具与在线用同一套参数，逐位等值约定）；设备 E 剔除与不剔除注入区间各跑一遍。

**判读口径**（运行前写定，均为测量项）：

1. 平稳日上的事件数，逐台、逐族（长记忆、逐日统计量超门槛、离群率确认）。理论预期为零。
2. 三月事件的起点与全程（三月二十二日至二十七日）：逐台逐通道第一次长记忆事件的日期、第一次离群率候选与确认的时刻、逐日统计量越过位置门槛零点五与尺度门槛三点零的日期；理论预期气体通道由长记忆与逐日统计量报，起点由离群率先报。
3. 尺度漂移日：逐日统计量的宽度倍数与长记忆事件是否一致。
4. 四月的五个共模气体时段（数据事实第三十五条候选）：逐台气体通道的长记忆事件与离群率事件；预期至少七台同日报，这是"共模漂移下不误报局部异常"（理论线回传给数据层验证的核心考题）的输入。
5. C 的日照直射日与傍晚气体上升：预期长记忆不报（日尺度上差异小），离群率可能候选不确认。
6. 注入（不剔除的一遍）：十四段逐段记录离群率的候选与确认，长记忆与逐日统计量在注入当日是否越门槛；预期离群率对尖峰与阶跃候选、持续性核对不确认，长记忆不报。
7. 新增——夏令时切换日（三月二十七日）：按当地时间与按世界协调时各算一遍长记忆，记录两者在切换日前后的差异，证明按当地时间的必要性。
8. 新增——两层同报表：把性能层默认组合的事件与本阶段事件按片段并排，逐片段写明报警的层、通道与时刻先后。
9. 新增——理论第五项验证：原文方案、分布检验加邦费罗尼、卡方校准似然比三种方案在第一、二、四条上的结果并排。

参数不做网格；显著性水平、D 零与质量门槛都是运行前推导或写定的，报告只给出它们的推导表。
